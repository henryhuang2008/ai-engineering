Voice agent, LiveKit room — run it

The same expense agent, talking through a LiveKit room instead of a terminal. You open a browser page, press Connect, and speak. LiveKit handles the microphone, silence detection, interruptions and playback; the worker runs Qwen ASR → LangGraph → Qwen TTS. The server is one Docker container.

The one-line model A room carries the audio; your code only carries the turn. No sounddevice, no Enter key, no playback loop.

1 — Start the LiveKit server

cd assets/examples/example-livekit-langgraph
docker compose up -d
docker compose ps

docker-compose.yml runs livekit/livekit-server:v1.13.11 with livekit.yaml and publishes three ports:

PortProtocolUse
7880TCPHTTP + WebSocket signalling
7881TCPWebRTC over TCP (fallback)
7882UDPWebRTC media, one shared port

The config uses udp_port: 7882, not a one-port range: a range allocates one port per participant, and the second participant then gets no UDP candidate. The key pair is local-only (devkey / a 36-character dev secret) and matches .env.example.

2 — Configure the worker

uv sync
Copy-Item .env.example .env

setx DEEPSEEK_API_KEY "sk-..."
setx DASHSCOPE_API_KEY "sk-..."

Put the Supabase URI in SUPABASE_URI and the customer id from seed.py in CUSTOMER_ID — same as the terminal example. Then: 

uv run python check.py

It checks packages, both keys, the database, the MCP tools, both Qwen plugins, and that ws://127.0.0.1:7880 answers.

3 — Run the worker and the client

Terminal one, the worker (leave it running):

uv run python agent.py dev

Terminal two, a token and the page:

uv run python make_token.py
cd client
python -m http.server 8000

Open http://localhost:8000, paste the token, press Connect, allow the microphone. The status line should say microphone on; Luna greets you. Say:

“Create an expense for a taxi to the airport, thirty dollars.”

Stop talking and the VAD ends your turn — no keypress. Talk over her and she stops. To leave, press Disconnect or close the tab; there is no exit word.

The page must be served over http://localhost; browsers block the microphone on file://, and the page shows a yellow banner if you open it as a file.

No browser? Run the headless turn

uv run python smoke.py

It joins a fresh room, publishes a synthesized question as its microphone, records the agent's track and prints both transcripts: 

[1/4] speaking the question with qwen3-tts-flash
[2/4] joining smoke-...
[3/4] agent joined; waiting for the greeting
[4/4] sending the question

-- transcripts --
  Luna   Hi, I'm Luna, your expense manager. What would you like to log?
  smoke  Create an expense for a taxi to the airport, $30 .
  Luna   Done — I logged thirty dollars for the taxi to the airport under travel.
