# 0003 — Function calling: the model asks, your code acts

One LangChain handle (`ChatDeepSeek`), five stages. The model never runs anything: it
returns a **request** (`AIMessage.tool_calls`), your code decides whether to run it,
executes the real function, and reports back with a `ToolMessage`. Repeat until the
model answers in plain text — that loop is the atom of agency.

| stage | what it shows | stable result |
|---|---|---|
| 1. catalog | two `@tool` functions → name, description, parameter schema. The model never sees the bodies | 2 tools; `required` is `['ticket_id']` and `['ticket_id', 'amount_usd']` |
| 2. one call | `bind_tools()` → `AIMessage.tool_calls` → `execute()` → `ToolMessage` → one more call | thread **3 → 5** messages; the tool result carries the call id |
| 3. the loop | a refund needs two rounds (look up, then refund); the loop ends when `tool_calls` is empty | iterations **2–3**, `stopped: answer` |
| 4. the guard | `T-1002` is not refundable → the tool returns `{"error": "ticket not refundable"}` and the model must read it | `stopped: answer`, no invented success |
| 5. the cap | `max_iterations=1` on the same refund task | `stopped: budget`, 1 iteration, empty answer |

Model *wording* varies between runs. Message counts, call ids, and the loop's stop
reason are structural — `evals.py` asserts those, not the sentences.

## What the self-tests cover

Everything that does not need the network: the fixture, both tool contracts
(required arguments, description text), the tool bodies (refund allowed / refused /
unknown ticket), the catalog the model receives, `execute()` for good calls, unknown
tools and invalid arguments, the loop's control flow (answer vs budget, message

`get_ticket_status`.

## DeepSeek notes

- `deepseek-flash` supports tool calls; `deepseek-v4-pro` is the larger option. Same
  key, same base URL.
- The lab disables DeepSeek thinking for speed. If you turn thinking on
  (`extra_body={"thinking": {"type": "enabled"}}`), tool turns require every earlier
  `reasoning_content` to be echoed back or the API answers 400 — which is why the
  loop keeps the raw `AIMessage` instead of rebuilding messages by hand.
- `strict` mode (Beta) pins argument shapes to your JSON schema: use the
  `https://api.deepseek.com/beta` base URL and set `strict: true` per function.
- LangChain maps `AIMessage.tool_calls` and `ToolMessage` onto DeepSeek's OpenAI-shaped
  wire format, so the same loop runs unchanged on other providers.

function_calling_lab.py

"""0003-function-calling - the agent loop, by hand, with LangChain + DeepSeek.

Five stages on one model handle:

  1. catalog   two @tool functions -> the JSON schema the model actually reads
  2. one call  bind_tools -> AIMessage.tool_calls -> your code runs the tool ->
               ToolMessage -> one more call. ONE round trip, not an agent.
  3. the loop  a refund needs two rounds (look up, then refund). The loop keeps
               calling until the model stops asking for tools: the agent loop.
  4. the guard a non-refundable ticket returns an error; the model must read it
               and recover instead of claiming success.
  5. the cap   max_iterations on a task that needs two rounds: the production
               guard fires instead of spinning forever.

This lab talks to the live DeepSeek API. Set DEEPSEEK_API_KEY first:

  PowerShell (this session):  $env:DEEPSEEK_API_KEY = "sk-..."
  PowerShell (persist):       setx DEEPSEEK_API_KEY "sk-..."   # reopen the terminal

Get a key at https://platform.deepseek.com/api_keys. No key -> exit 1 with these
instructions, never a guess.
"""

from __future__ import annotations

import json
import os
import sys
from dataclasses import dataclass
from typing import Any

from langchain_core.messages import (
    AIMessage,
    BaseMessage,
    HumanMessage,
    SystemMessage,
    ToolMessage,
)
from langchain_core.tools import BaseTool, tool

MODEL = os.getenv("DEEPSEEK_MODEL", "deepseek-flash")
BASE_URL = os.getenv("DEEPSEEK_BASE_URL", "https://api.deepseek.com")
MAX_ITERATIONS = int(os.getenv("MAX_ITERATIONS", "10"))

SYSTEM = "You are a support agent. Use tools when you need facts. Answer in one or two sentences."
QUESTION_STATUS = "What's the status of ticket T-1001?"
QUESTION_REFUND = "Ticket T-1001 says I was overcharged 20 dollars. Check it and issue the refund."
QUESTION_REFUSED = "Ticket T-1002 was charged 20 dollars. Refund it now."

# --- the world the tools can touch (fixture) --------------------------------

TICKETS = {
    "T-1001": {"status": "open", "plan": "pro", "refundable": True},
    "T-1002": {"status": "closed", "plan": "free", "refundable": False},
}


@tool
def get_ticket_status(ticket_id: str) -> dict:
    """Look up the status and plan of a support ticket by its id, for example T-1001."""
    return TICKETS.get(ticket_id, {"error": "unknown ticket"})


@tool
def issue_refund(ticket_id: str, amount_usd: float) -> dict:
    """Issue a refund for a refundable ticket. Check the status first and only refund amounts the customer was actually charged."""
    ticket = TICKETS.get(ticket_id)
    if ticket is None:
        return {"error": "unknown ticket"}
    if not ticket["refundable"]:
        return {"error": "ticket not refundable"}
    return {"refunded_usd": amount_usd, "ticket": ticket_id}


TOOLS = [get_ticket_status, issue_refund]
REGISTRY: dict[str, BaseTool] = {item.name: item for item in TOOLS}


# --- model wiring -----------------------------------------------------------


def missing_key_message() -> str:
    return (
        "DEEPSEEK_API_KEY is not set.\n"
        '  PowerShell (this session):  $env:DEEPSEEK_API_KEY = "sk-..."\n'
        '  PowerShell (persist):       setx DEEPSEEK_API_KEY "sk-..."   # reopen terminal\n'
        "  Get a key:                  https://platform.deepseek.com/api_keys"
    )


def build_model() -> Any:
    """Return a live ChatDeepSeek handle, or explain exactly what is missing."""
    if not os.getenv("DEEPSEEK_API_KEY"):
        raise RuntimeError(missing_key_message())

    from langchain_deepseek import ChatDeepSeek

    return ChatDeepSeek(
        model=os.getenv("DEEPSEEK_MODEL", MODEL),
        api_key=os.getenv("DEEPSEEK_API_KEY"),
        api_base=os.getenv("DEEPSEEK_BASE_URL", BASE_URL),
        temperature=0,
        max_retries=2,
        timeout=60,
        # DeepSeek's thinking mode requires every earlier reasoning block to be
        # echoed back on tool turns; this lab is about the loop, so keep it off.
        extra_body={"thinking": {"type": "disabled"}},
    )


# --- the mechanics the lesson is about --------------------------------------


def catalog() -> list[dict[str, Any]]:
    """What the model is allowed to know about each tool. Nothing else is sent."""
    rows: list[dict[str, Any]] = []
    for item in TOOLS:
        schema = item.args_schema.model_json_schema()
        rows.append(
            {
                "name": item.name,
                "description": item.description,
                "required": schema.get("required", []),
                "properties": sorted(schema.get("properties", {})),
            }
        )
    return rows


def execute(call: dict[str, Any]) -> ToolMessage:
    """Run one requested tool call and wrap the result for the model.

    Unknown tools and invalid arguments come back as data, not exceptions: the
    model reads them and corrects itself on the next round.
    """
    name = call["name"]
    arguments = call["args"]
    tool_obj = REGISTRY.get(name)
    if tool_obj is None:
        payload: Any = {"error": f"unknown tool {name}"}
    else:
        try:
            payload = tool_obj.invoke(arguments)
        except Exception as exc:  # noqa: BLE001 - validation errors are data here
            payload = {"error": f"invalid arguments for {name}: {type(exc).__name__}"}
    return ToolMessage(content=json.dumps(payload), tool_call_id=call["id"])


@dataclass
class LoopResult:
    answer: str
    messages: list[BaseMessage]
    iterations: int
    stopped: str  # "answer" or "budget"


def run_loop(model: Any, question: str, *, max_iterations: int = MAX_ITERATIONS) -> LoopResult:
    """The agent loop: call, act, observe, repeat until plain text or the cap."""
    bound = model.bind_tools(TOOLS)
    messages: list[BaseMessage] = [
        SystemMessage(content=SYSTEM),
        HumanMessage(content=question),
    ]
    for step in range(1, max_iterations + 1):
        reply = bound.invoke(messages)
        messages.append(reply)
        if not reply.tool_calls:
            return LoopResult(str(reply.content), messages, step, "answer")
        # Keep the raw AIMessage above: rebuilding it by hand loses fields the
        # provider expects on the next request (ids, reasoning, provider extras).
        for call in reply.tool_calls:
            messages.append(execute(call))
    return LoopResult("", messages, max_iterations, "budget")


# --- output helpers ---------------------------------------------------------


def describe(message: BaseMessage) -> str:
    if message.type == "ai" and message.tool_calls:
        calls = ", ".join(f"{c['name']}({c['args']})" for c in message.tool_calls)
        return f"{message.type:<6} wants {calls}"
    text = message.content if isinstance(message.content, str) else str(message.content)
    return f"{message.type:<6} {text}"


def print_trace(messages: list[BaseMessage], start: int = 1) -> None:
    for index, message in enumerate(messages, start=start):
        print(f"  {index} {describe(message)}")


# --- stages -----------------------------------------------------------------


def stage_catalog() -> None:
    print("== 1. catalog: the only thing the model knows about your code ==")
    for row in catalog():
        print(f"{row['name']}{row['required']}")
        print(f'  description: "{row["description"]}"')
    print("  the model never sees the function bodies - only this catalog")
    print()


def stage_one_call(model: Any) -> None:
    print("== 2. one round trip: the model asks, your code acts =============")
    bound = model.bind_tools(TOOLS)
    messages = [SystemMessage(content=SYSTEM), HumanMessage(content=QUESTION_STATUS)]
    reply = bound.invoke(messages)
    call = reply.tool_calls[0]
    print(f"model requested: {call['name']}({call['args']})")
    print(f"tool_call_id:    {call['id']}")

    result = execute(call)
    print(f"your code ran:   {result.content}")

    thread = messages + [reply, result]
    final = bound.invoke(thread)
    print(f"final answer:    {final.content}")
    print(f"thread length:   {len(thread) + 1} messages (system, human, ai, tool, ai)")
    print()


def stage_loop(model: Any) -> None:
    print("== 3. the loop: two rounds, one answer ===========================")
    result = run_loop(model, QUESTION_REFUND)
    print_trace(result.messages)
    print(f"iterations:      {result.iterations} (stopped: {result.stopped})")
    print(f"answer:          {result.answer}")
    print()


def stage_guard(model: Any) -> None:
    print("== 4. the guard: a refused action is data, not a crash ===========")
    result = run_loop(model, QUESTION_REFUSED)
    print_trace(result.messages)
    print(f"iterations:      {result.iterations} (stopped: {result.stopped})")
    print(f"answer:          {result.answer}")
    print("  the tool said no; the model had to read that and stop pretending")
    print()


def stage_cap(model: Any) -> None:
    print("== 5. the cap: max_iterations stops a spinning loop ==============")
    result = run_loop(model, QUESTION_REFUND, max_iterations=1)
    print(f"iterations:      {result.iterations} (stopped: {result.stopped})")
    print(f"messages kept:   {len(result.messages)} ({result.messages[-1].type} last)")
    print("  in production this is your budget guard, not an error tax")
    print()


def run() -> int:
    try:
        model = build_model()
    except RuntimeError as error:
        print(f"error: {error}", file=sys.stderr)
        return 1

    print(f"DeepSeek via LangChain -- live model ({MODEL})")
    print()
    stage_catalog()
    stage_one_call(model)
    stage_loop(model)
    stage_guard(model)
    stage_cap(model)
    print("done: 5 stages, live DeepSeek calls")
    return 0


def main() -> int:
    try:
        return run()
    except Exception as error:  # noqa: BLE001 - surface the provider error, keep exit codes
        print(f"error: {type(error).__name__}: {error}", file=sys.stderr)
        print(
            "check DEEPSEEK_API_KEY, account balance, and network access.",
            file=sys.stderr,
        )
        return 1


if __name__ == "__main__":
    raise SystemExit(main())

"""Self-tests for 0003-function-calling.

No fake model: the lab talks to live DeepSeek. Everything here runs offline -
tool contracts, the catalog, tool execution and error handling, the loop's
control flow (driven by a test double defined below, not by the lab), the
missing-key instructions, the uv project - plus one live smoke when a key is set.
"""

from __future__ import annotations

import json
import os
import re
import subprocess
import sys
import tomllib
from pathlib import Path

import function_calling_lab as lab
from langchain_core.messages import AIMessage, HumanMessage, SystemMessage, ToolMessage

HERE = Path(__file__).resolve().parent
PY = sys.executable
CHECKS: list[str] = []


def check(name: str, condition: bool, detail: str = "") -> None:
    if not condition:
        raise AssertionError(f"{name}: {detail}" if detail else name)
    CHECKS.append(name)


def clean_env() -> dict[str, str]:
    env = {k: v for k, v in os.environ.items() if not k.startswith("DEEPSEEK_")}
    env.pop("OPENAI_API_KEY", None)
    return env


def run_lab(env: dict[str, str], timeout: int = 90):
    return subprocess.run(
        [PY, "function_calling_lab.py"],
        cwd=HERE,
        env=env,
        capture_output=True,
        text=True,
        encoding="utf-8",
        errors="replace",
        timeout=timeout,
    )


def with_env(values: dict[str, str]):
    """Temporarily set env vars, then restore exactly."""

    class _Ctx:
        def __enter__(self):
            self.old = os.environ.copy()
            os.environ.update(values)

        def __exit__(self, *args):
            os.environ.clear()
            os.environ.update(self.old)

    return _Ctx()


class _StubBound:
    """Answers the loop with pre-built AIMessages; records what it was sent."""

    def __init__(self, replies: list[AIMessage]) -> None:
        self.replies = list(replies)
        self.sent: list[list] = []

    def invoke(self, messages):
        self.sent.append(list(messages))
        return self.replies.pop(0) if self.replies else AIMessage(content="done")


class StubModel:
    """Test double for the loop's control flow. The lab itself has no fake model."""

    def __init__(self, replies: list[AIMessage]) -> None:
        self.bound = _StubBound(replies)
        self.tools: list = []

    def bind_tools(self, tools):
        self.tools = list(tools)
        return self.bound


def call_message(name: str, args: dict, call_id: str) -> AIMessage:
    return AIMessage(content="", tool_calls=[{"name": name, "args": args, "id": call_id}])


# --- tests -----------------------------------------------------------------


def test_fixture() -> None:
    check("two tickets in the fixture", len(lab.TICKETS) == 2, str(sorted(lab.TICKETS)))
    check("T-1001 refundable", lab.TICKETS["T-1001"]["refundable"] is True)
    check("T-1002 not refundable", lab.TICKETS["T-1002"]["refundable"] is False)


def test_tool_contracts() -> None:
    check("tool count", len(lab.TOOLS) == 2, str(len(lab.TOOLS)))
    check("registry keys", sorted(lab.REGISTRY) == ["get_ticket_status", "issue_refund"])

    lookup = lab.get_ticket_status.args_schema.model_json_schema()
    check("lookup name", lab.get_ticket_status.name == "get_ticket_status")
    check("lookup takes ticket_id", lookup.get("required") == ["ticket_id"])
    check("lookup description names the id", "id" in lab.get_ticket_status.description.lower())

    refund = lab.issue_refund.args_schema.model_json_schema()
    check("refund takes two args", sorted(refund.get("required", [])) == ["amount_usd", "ticket_id"])
    check(
        "refund description carries policy",
        "check the status first" in lab.issue_refund.description.lower(),
    )


def test_tool_behaviour() -> None:
    status = lab.get_ticket_status.invoke({"ticket_id": "T-1001"})
    check("lookup returns a dict", isinstance(status, dict), type(status).__name__)
    check("lookup reports open", status["status"] == "open", str(status))
    check(
        "lookup handles unknown ids",
        "error" in lab.get_ticket_status.invoke({"ticket_id": "T-9999"}),
    )

    ok = lab.issue_refund.invoke({"ticket_id": "T-1001", "amount_usd": 20})
    check("refund runs for T-1001", ok == {"refunded_usd": 20, "ticket": "T-1001"}, str(ok))
    refused = lab.issue_refund.invoke({"ticket_id": "T-1002", "amount_usd": 20})
    check("refund refused for T-1002", refused == {"error": "ticket not refundable"}, str(refused))
    unknown = lab.issue_refund.invoke({"ticket_id": "T-9999", "amount_usd": 20})
    check("refund refuses unknown ticket", unknown == {"error": "unknown ticket"}, str(unknown))


def test_catalog() -> None:
    rows = lab.catalog()
    check("catalog lists two tools", len(rows) == 2, str(len(rows)))
    by_name = {row["name"]: row for row in rows}
    check("catalog has both names", set(by_name) == {"get_ticket_status", "issue_refund"})
    check("catalog exposes required args", by_name["issue_refund"]["required"] == ["ticket_id", "amount_usd"])
    check(
        "catalog exposes properties",
        by_name["get_ticket_status"]["properties"] == ["ticket_id"],
        str(by_name["get_ticket_status"]["properties"]),
    )
    check(
        "catalog carries the descriptions",
        all(row["description"] for row in rows),
        str([row["description"] for row in rows]),
    )


def test_execute() -> None:
    good = lab.execute({"name": "get_ticket_status", "args": {"ticket_id": "T-1001"}, "id": "call_1"})
    check("execute returns a ToolMessage", isinstance(good, ToolMessage), type(good).__name__)
    check("tool_call_id is preserved", good.tool_call_id == "call_1", good.tool_call_id)
    check("payload is JSON", json.loads(good.content)["status"] == "open", good.content)

    unknown = lab.execute({"name": "delete_everything", "args": {}, "id": "call_2"})
    check("unknown tool becomes an error payload", "unknown tool" in unknown.content, unknown.content)
    check("unknown tool keeps the id", unknown.tool_call_id == "call_2")

    bad_args = lab.execute({"name": "issue_refund", "args": {"ticket_id": "T-1001"}, "id": "call_3"})
    check("invalid arguments become an error payload", "invalid arguments" in bad_args.content, bad_args.content)


def test_loop_control_flow() -> None:
    stub = StubModel(
        [
            call_message("get_ticket_status", {"ticket_id": "T-1001"}, "call_a"),
            AIMessage(content="T-1001 is open on the pro plan."),
        ]
    )
    result = lab.run_loop(stub, "status of T-1001?")
    check("loop stops on plain text", result.stopped == "answer", result.stopped)
    check("loop counts two iterations", result.iterations == 2, str(result.iterations))
    check("answer comes from the model", "open" in result.answer, result.answer)
    check(
        "message shapes are system/human/ai/tool/ai",
        [m.type for m in result.messages] == ["system", "human", "ai", "tool", "ai"],
        str([m.type for m in result.messages]),
    )
    check("tool result is attached to the call", result.messages[3].tool_call_id == "call_a")
    check("loop binds both tools", len(stub.tools) == 2, str(len(stub.tools)))
    check(
        "second call re-sends the tool result",
        any(m.type == "tool" for m in stub.bound.sent[1]),
        str([m.type for m in stub.bound.sent[1]]),
    )


def test_loop_budget() -> None:
    stub = StubModel([call_message("get_ticket_status", {"ticket_id": "T-1001"}, f"call_{i}") for i in range(5)])
    result = lab.run_loop(stub, "loop forever", max_iterations=3)
    check("budget stops the loop", result.stopped == "budget", result.stopped)
    check("budget honours max_iterations", result.iterations == 3, str(result.iterations))
    check("budget returns no answer", result.answer == "", result.answer)
    check("budget keeps the transcript", len(result.messages) == 8, str(len(result.messages)))

def test_uv_project() -> None:
    """The uv project is the single source of dependencies; keep it honest."""
    pyproject = HERE / "pyproject.toml"
    check("pyproject.toml exists", pyproject.exists())
    data = tomllib.loads(pyproject.read_text(encoding="utf-8"))
    declared = {
        re.split(r"[<>=!~ ]", dep, maxsplit=1)[0] for dep in data["project"]["dependencies"]
    }
    check(
        "declares langchain, langchain-deepseek, pydantic",
        {"langchain", "langchain-deepseek", "pydantic"} <= declared,
        str(sorted(declared)),
    )


def test_live_smoke() -> tuple[bool, str]:
    if not os.getenv("DEEPSEEK_API_KEY"):
        return False, "skipped (no DEEPSEEK_API_KEY)"
    model = lab.build_model()
    reply = model.bind_tools(lab.TOOLS).invoke(
        [
            SystemMessage(content=lab.SYSTEM),
            HumanMessage(content=lab.QUESTION_STATUS),
        ]
    )
    check("live reply is an AIMessage", isinstance(reply, AIMessage), type(reply).__name__)
    check("live reply requested the lookup", bool(reply.tool_calls), str(reply.tool_calls))
    check("live call names a declared tool", reply.tool_calls[0]["name"] in lab.REGISTRY)
    return True, "ran one live tool-calling call"

def main() -> int:
    failures = 0
    for index, (name, test) in enumerate(TESTS, start=1):
        try:
            test()
            print(f"ok {index:02d} {name}")
        except Exception as error:  # noqa: BLE001 - a test runner reports everything
            failures += 1
            print(f"FAIL {index:02d} {name}: {error}")

    try:
        ran, note = test_live_smoke()
    except Exception as error:  # noqa: BLE001
        failures += 1
        print(f"FAIL 13 live smoke: {error}")
    else:
        print(f"ok 13 live smoke: {note}")
        if not ran:
            print("     set DEEPSEEK_API_KEY to include the live call")

    total = len(CHECKS)
    print(f"\n{total} checks passed, {failures} failed")
    return 0 if failures == 0 else 1


if __name__ == "__main__":
    raise SystemExit(main())
