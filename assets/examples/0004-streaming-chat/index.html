# 0004 — Streaming chat: FastAPI + LangChain, Next.js prompt input

A two-service chat product: **Python owns every AI decision**, Next.js owns the shell.
One DeepSeek model handle, one SSE endpoint, one thin translator, one shadcn prompt input.

Two folders, one job each:

```
0004-streaming-chat\
  backend\      Python + FastAPI + LangChain  -> the model, the key, the SSE endpoint
  frontend\     Next.js + shadcn prompt input -> the screen; no key, no model call
```

| layer | role | file |
|---|---|---|
| FastAPI | validates the conversation, calls `ChatDeepSeek.astream()`, frames each delta as `data: {"delta": "..."}` | `backend/main.py` |
| bare client | proves the Python side streams before Next.js exists; prints TTFT | `backend/test-client.html` |
| Next.js route | protocol translator only — no key, no model call | `frontend/app/api/chat/route.ts` |
| Next.js page | `useChat` + shadcn `InputGroup` prompt field | `frontend/app/page.tsx` |

## 404, 405, 502 — which layer broke

The page prints whatever came back. Three different failures, three different fixes:

| what you see | what it means | fix |
|---|---|---|
| a Next.js **404** HTML page ("This page could not be found") | no route handler at `/api/chat` — the file is in the wrong folder or misnamed | put it at `frontend\app\api\chat\route.ts` (or `src\app\api\chat\route.ts` if your app uses `src\`), then restart `npm run dev` |
| **502** with a plain-text body naming `PY_BACKEND` | the route is fine, Python isn't listening | start `uv run uvicorn main:app --reload` in `backend\` |
| a sentence from DeepSeek (e.g. `401 … invalid api key`) | both services are up; the model call failed | read the uvicorn terminal, fix `DEEPSEEK_API_KEY` |

Check the route without opening the browser:

```powershell
curl.exe -i http://localhost:3000/api/chat
# 405 Method Not Allowed -> the route exists (it only exports POST)   ✅
# 404 Not Found          -> the file is not at app\api\chat\route.ts  ❌
```

That asymmetry is your fastest diagnostic: Next.js answers `405` for a known route with
an unsupported method, and `404` when the segment doesn't exist at all. Creating
`app\api\chat\` while `npm run dev` is running usually works, but if the 404 persists,
restart the dev server — the route tree is read at boot in some versions.

## Wire format

Every delta is its own SSE event with a JSON body:

```
data: {"delta": "Stream"}

data: {"delta": "ing works"}

data: {"done": true}
```

JSON on purpose: a delta can contain a newline or a quote, and a raw `data: <text>`
frame would split one token into two events. Errors travel the same way
(`{"error": "..."}`) so the UI can show what broke instead of hanging.

## What the self-tests cover

Offline (69 checks): the pydantic request contract (roles restricted to
`system|user|assistant`, empty content and empty history rejected), the
message adapter to LangChain objects, SSE framing (blank-line termination, newline
and unicode safety, JSON round trip, done/error frames), the chunk-to-text reader
(string and block content), the model wiring (`ChatDeepSeek`, `deepseek-flash`,
`api.deepseek.com`, thinking disabled), environment overrides, the missing-key
message (startup refusal + CLI exit 1), the stack guard (no OpenAI SDK, no
`gpt-4o`, LangChain + pydantic + FastAPI present, page uses `InputGroupTextarea` and
turns a 404 HTML body into a hint, route parses SSE, forwards the abort signal, answers
failures as plain text, and the README documents the 405 check), and the uv project.

With a key, three more checks run: a live `astream()` must yield at least one
delta, the deltas must join into text, and the stream must actually be chunked.

## DeepSeek notes

- `deepseek-flash` streams tool calls, structured output, and plain text; the same
  loop works on other LangChain providers.
- The lab disables thinking (`extra_body={"thinking": {"type": "disabled"}}`).
  With thinking on, DeepSeek streams `reasoning_content` before the answer — fine
  for a reasoning UI, but it muddies "time to first *answer* token".
- `X-Accel-Buffering: no` is set on the response; nginx and friends buffer SSE by
  default, which turns a stream into one big blob at the end.

backend/main.py

"""0004-streaming-chat - FastAPI + LangChain + DeepSeek, streamed to the browser.

One endpoint, three jobs:

  1. validate the conversation          pydantic models, roles as a Literal
  2. stream the model's reply           ChatDeepSeek.astream() -> AIMessageChunk
  3. frame each delta as SSE            `data: {"delta": "..."}` + a final done

The framing is JSON on purpose: a delta often contains a newline, and a raw
`data: <text>` frame would split one token into two events.

This lab talks to the live DeepSeek API. Set DEEPSEEK_API_KEY first:

  PowerShell (this session):  $env:DEEPSEEK_API_KEY = "sk-..."
  PowerShell (persist):       setx DEEPSEEK_API_KEY "sk-..."   # reopen the terminal

Get a key at https://platform.deepseek.com/api_keys. No key -> startup fails with
these instructions, never a guess.
"""

from __future__ import annotations

import json
import os
import sys
from contextlib import asynccontextmanager
from pathlib import Path
from typing import Any, AsyncIterator, Literal

from fastapi import FastAPI
from fastapi.responses import HTMLResponse, StreamingResponse
from langchain_core.messages import AIMessage, BaseMessage, HumanMessage, SystemMessage
from pydantic import BaseModel, Field

MODEL = os.getenv("DEEPSEEK_MODEL", "deepseek-flash")
BASE_URL = os.getenv("DEEPSEEK_BASE_URL", "https://api.deepseek.com")
HERE = Path(__file__).resolve().parent

SYSTEM = "You are a concise support assistant. Answer in two or three sentences."


# --- request contract -------------------------------------------------------


class Message(BaseModel):
    role: Literal["system", "user", "assistant"]
    content: str = Field(min_length=1)


class ChatIn(BaseModel):
    messages: list[Message] = Field(min_length=1)


LC_MESSAGES = {"system": SystemMessage, "user": HumanMessage, "assistant": AIMessage}


def to_lc(message: Message) -> BaseMessage:
    """Pydantic message -> LangChain message. That is the whole adapter."""
    return LC_MESSAGES[message.role](content=message.content)


# --- model wiring -----------------------------------------------------------


def missing_key_message() -> str:
    return (
        "DEEPSEEK_API_KEY is not set.\n"
        '  PowerShell (this session):  $env:DEEPSEEK_API_KEY = "sk-..."\n'
        '  PowerShell (persist):       setx DEEPSEEK_API_KEY "sk-..."   # reopen terminal\n'
        "  Get a key:                  https://platform.deepseek.com/api_keys"
    )


def build_model() -> Any:
    """Return a live ChatDeepSeek handle, or explain exactly what is missing."""
    if not os.getenv("DEEPSEEK_API_KEY"):
        raise RuntimeError(missing_key_message())

    from langchain_deepseek import ChatDeepSeek

    return ChatDeepSeek(
        model=os.getenv("DEEPSEEK_MODEL", MODEL),
        api_key=os.getenv("DEEPSEEK_API_KEY"),
        api_base=os.getenv("DEEPSEEK_BASE_URL", BASE_URL),
        temperature=0.3,
        max_retries=2,
        timeout=60,
        # Thinking mode would stream reasoning_content first; this lab is about
        # the SSE seam, so keep the wire simple and the first token honest.
        extra_body={"thinking": {"type": "disabled"}},
    )


# --- SSE framing ------------------------------------------------------------


def sse(payload: dict[str, Any]) -> str:
    """One SSE event. JSON, so newlines and quotes inside a delta stay intact."""
    return f"data: {json.dumps(payload, ensure_ascii=False)}\n\n"


def text_of(chunk: Any) -> str:
    """AIMessageChunk.content is a str, or a list of content blocks."""
    content = getattr(chunk, "content", "")
    if isinstance(content, str):
        return content
    parts: list[str] = []
    for block in content or []:
        if isinstance(block, str):
            parts.append(block)
        elif isinstance(block, dict) and block.get("type") == "text":
            parts.append(str(block.get("text", "")))
    return "".join(parts)


async def stream_reply(payload: ChatIn) -> AsyncIterator[str]:
    """Call the model once, yield one SSE event per delta, then close the stream."""
    model = build_model()
    messages = [SystemMessage(content=SYSTEM), *(to_lc(message) for message in payload.messages)]

    try:
        async for chunk in model.astream(messages):
            delta = text_of(chunk)
            if delta:
                yield sse({"delta": delta})
    except Exception as error:  # noqa: BLE001 - the client must see why the stream died
        yield sse({"error": f"{type(error).__name__}: {error}"})
    finally:
        yield sse({"done": True})


# --- app --------------------------------------------------------------------


@asynccontextmanager
async def lifespan(app: FastAPI):
    """Fail at startup, not on the first message, when the key is missing."""
    if not os.getenv("DEEPSEEK_API_KEY"):
        raise RuntimeError(missing_key_message())
    yield


app = FastAPI(title="0004 streaming chat", lifespan=lifespan)


@app.get("/", response_class=HTMLResponse)
async def index() -> str:
    """The bare test client: proves the Python side streams before Next.js exists."""
    return (HERE / "test-client.html").read_text(encoding="utf-8")


@app.get("/health")
async def health() -> dict[str, Any]:
    return {"ok": True, "model": MODEL, "key": bool(os.getenv("DEEPSEEK_API_KEY"))}


@app.post("/chat-stream")
async def chat_stream(payload: ChatIn) -> StreamingResponse:
    return StreamingResponse(
        stream_reply(payload),
        media_type="text/event-stream",
        headers={
            "Cache-Control": "no-cache",
            "Connection": "keep-alive",
            # Proxies love to buffer SSE; this header turns that off for most.
            "X-Accel-Buffering": "no",
        },
    )


def main() -> int:
    try:
        build_model()
    except RuntimeError as error:
        print(f"error: {error}", file=sys.stderr)
        return 1
    print(f"ok: {MODEL} reachable config; start the server with:")
    print("  uv run uvicorn main:app --reload")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

"""Self-tests for 0004-streaming-chat.

No fake model: the lab talks to live DeepSeek. Everything here runs offline -
the pydantic request contract, the message adapter, SSE framing (including the
newline case that breaks naive `data: <text>` streams), the chunk-to-text
reader, model wiring, the missing-key instructions, the uv project - plus one
live stream when a key is set.
"""

from __future__ import annotations

import asyncio
import json
import os
import re
import subprocess
import sys
import tomllib
from pathlib import Path

from langchain_core.messages import AIMessage, AIMessageChunk, HumanMessage, SystemMessage
from pydantic import ValidationError

import main as lab

HERE = Path(__file__).resolve().parent
PY = sys.executable
CHECKS: list[str] = []


def check(name: str, condition: bool, detail: str = "") -> None:
    if not condition:
        raise AssertionError(f"{name}: {detail}" if detail else name)
    CHECKS.append(name)


def clean_env() -> dict[str, str]:
    env = {k: v for k, v in os.environ.items() if not k.startswith("DEEPSEEK_")}
    env.pop("OPENAI_API_KEY", None)
    env.pop("PY_BACKEND", None)
    return env


def with_env(values: dict[str, str]):
    """Temporarily set env vars, then restore exactly."""

    class _Ctx:
        def __enter__(self):
            self.old = os.environ.copy()
            os.environ.update(values)

        def __exit__(self, *args):
            os.environ.clear()
            os.environ.update(self.old)

    return _Ctx()


# --- request contract -------------------------------------------------------


def test_message_contract() -> None:
    good = lab.Message(role="user", content="hello")
    check("valid message accepted", good.role == "user" and good.content == "hello")

    for role in ("system", "user", "assistant"):
        check(f"role {role} allowed", lab.Message(role=role, content="x").role == role)

    try:
        lab.Message(role="tool", content="x")
    except ValidationError:
        CHECKS.append("role tool rejected")
    else:
        raise AssertionError("role tool should be rejected")

    try:
        lab.Message(role="user", content="")
    except ValidationError:
        CHECKS.append("empty content rejected")
    else:
        raise AssertionError("empty content should be rejected")

    lab.ChatIn(messages=[good])
    CHECKS.append("chat with one message accepted")

    try:
        lab.ChatIn(messages=[])
    except ValidationError:
        CHECKS.append("empty history rejected")
    else:
        raise AssertionError("empty history should be rejected")


def test_adapter() -> None:
    pairs = [
        ("system", SystemMessage),
        ("user", HumanMessage),
        ("assistant", AIMessage),
    ]
    for role, expected in pairs:
        built = lab.to_lc(lab.Message(role=role, content="hello there"))
        check(f"{role} maps to {expected.__name__}", isinstance(built, expected), type(built).__name__)
        check(f"{role} keeps the text", built.content == "hello there", str(built.content))
    check(
        "adapter covers every allowed role",
        set(lab.LC_MESSAGES) == {"system", "user", "assistant"},
        str(sorted(lab.LC_MESSAGES)),
    )


# --- wire format ------------------------------------------------------------


def test_sse_framing() -> None:
    frame = lab.sse({"delta": "hi"})
    check("frame starts with data: ", frame.startswith("data: "), repr(frame))
    check("frame ends with a blank line", frame.endswith("\n\n"), repr(frame))
    body = frame[len("data: ") : -2]
    check("body is JSON", json.loads(body) == {"delta": "hi"}, body)

    tricky = lab.sse({"delta": "line one\nline two"})
    check("one event per delta, even with a newline", tricky.count("data: ") == 1, repr(tricky))
    check("newline survives the round trip", json.loads(tricky[6:-2])["delta"] == "line one\nline two")

    unicode_frame = lab.sse({"delta": "café → naïve"})
    check("unicode is not escaped", "café → naïve" in unicode_frame, unicode_frame)
    check("unicode parses back", json.loads(unicode_frame[6:-2])["delta"] == "café → naïve")

    done = lab.sse({"done": True})
    check("done frame is JSON", json.loads(done[6:-2]) == {"done": True}, done)

    error = lab.sse({"error": "boom"})
    check("error frame is JSON", json.loads(error[6:-2]) == {"error": "boom"}, error)


def test_chunk_text() -> None:
    check("string content passes through", lab.text_of(AIMessageChunk(content="abc")) == "abc")

    blocks = AIMessageChunk(
        content=[
            {"type": "text", "text": "ab"},
            {"type": "reasoning", "text": "thinking"},
            {"type": "text", "text": "cd"},
        ]
    )
    check("text blocks are joined", lab.text_of(blocks) == "abcd", lab.text_of(blocks))
    check("non-text blocks are dropped", "thinking" not in lab.text_of(blocks))

    empty = AIMessageChunk(content=[])
    check("empty content is empty text", lab.text_of(empty) == "", repr(lab.text_of(empty)))
    check("missing content is tolerated", lab.text_of(object()) == "")

def test_stack() -> None:

import { createUIMessageStream, createUIMessageStreamResponse } from "ai";
import type { UIMessage } from "ai";

export const maxDuration = 60;

const PY_BACKEND = process.env.PY_BACKEND ?? "http://127.0.0.1:8000";

type Frame = { delta?: string; error?: string; done?: boolean };

/** Keep only the text parts; the UI message carries tool/attachment parts too. */
function textOf(message: UIMessage): string {
  return message.parts.map((part) => (part.type === "text" ? part.text : "")).join("");
}

/**
 * Plain text, never an HTML page: useChat shows `error.message` verbatim, and a
 * 500 from this file would hand the user a wall of markup instead of a sentence.
 */
function plain(body: string, status: number): Response {
  return new Response(body, {
    status,
    headers: { "Content-Type": "text/plain; charset=utf-8" },
  });
}

export async function POST(req: Request) {
  let messages: UIMessage[];
  try {
    ({ messages } = (await req.json()) as { messages: UIMessage[] });
  } catch {
    return plain("request body is not JSON with a messages array", 400);
  }

  const history = messages
    .map((message) => ({ role: message.role, content: textOf(message) }))
    .filter((message) => message.content.length > 0);

  let upstream: Response;
  try {
    upstream = await fetch(`${PY_BACKEND}/chat-stream`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ messages: history }),
      // Client hits Stop -> the browser aborts this request -> Python stops too.
      signal: req.signal,
    });
  } catch (error) {
    if (req.signal.aborted) throw error; // the user pressed Stop, not a failure
    const detail = error instanceof Error ? error.message : String(error);
    return plain(
      `python backend unreachable at ${PY_BACKEND}\n` +
        `  start it:  uv run uvicorn main:app --reload\n` +
        `  detail:    ${detail}`,
      502,
    );
  }

  if (!upstream.ok || !upstream.body) {
    const detail = await upstream.text().catch(() => "");
    return plain(
      `python backend answered ${upstream.status} at ${PY_BACKEND}\n` +
        `  check the uvicorn terminal for the traceback\n` +
        `  detail: ${detail.slice(0, 600)}`,
      502,
    );
  }

  const textId = crypto.randomUUID();

  const stream = createUIMessageStream({
    execute: async ({ writer }) => {
      const reader = upstream.body!.getReader();
      const decoder = new TextDecoder();
      let buffer = "";
      let failure: unknown = null;

      writer.write({ type: "text-start", id: textId });

      try {
        while (true) {
          const { done, value } = await reader.read();
          if (done) break;
          buffer += decoder.decode(value, { stream: true });

          // SSE events end with a blank line; a chunk boundary can split one.
          let split: number;
          while ((split = buffer.indexOf("\n\n")) !== -1) {
            const raw = buffer.slice(0, split);
            buffer = buffer.slice(split + 2);
            if (!raw.startsWith("data: ")) continue;

            const frame = JSON.parse(raw.slice(6)) as Frame;
            if (frame.error) throw new Error(frame.error);
            if (frame.delta) {
              writer.write({ type: "text-delta", id: textId, delta: frame.delta });
            }
          }
        }
      } catch (error) {
        failure = error;
      } finally {
        writer.write({ type: "text-end", id: textId });
      }

      if (failure) throw failure;
    },
    onError: (error) => (error instanceof Error ? error.message : String(error)),
  });

  return createUIMessageStreamResponse({ stream });
}

/**
 * useChat hands back whatever the failing request returned. When the route file
 * lives in the wrong folder that "body" is Next.js's 404 HTML page, so translate
 * the two mistakes people actually make into a sentence instead of dumping markup.
 */
function errorText(error: Error): string {
  const raw = error.message ?? "";
  if (raw.includes("<!DOCTYPE html") || raw.includes("__next")) {
    return (
      "The browser got a Next.js page instead of your route handler — " +
      "route.ts is not at app/api/chat/route.ts (or src/app/api/chat/route.ts). " +
      "Move it there and let the dev server reload."
    );
  }
  return raw.length > 400 ? `${raw.slice(0, 400)}…` : raw;
}

const log = document.getElementById("log");
const form = document.getElementById("form");
const text = document.getElementById("text");
const send = document.getElementById("send");
const stats = document.getElementById("stats");

let history = [];

function addTurn(kind, body = "") {
  const el = document.createElement("div");
  el.className = `turn ${kind}`;
  el.textContent = body;
  log.appendChild(el);
  el.scrollIntoView({ block: "end", behavior: "smooth" });
  return el;
}

form.addEventListener("submit", async (event) => {
  event.preventDefault();
  const question = text.value.trim();
  if (!question || send.disabled) return;

  send.disabled = true;
  stats.textContent = "";
  addTurn("user", question);
  history.push({ role: "user", content: question });
  const answer = addTurn("bot");

  const started = performance.now();
  let firstTokenAt = 0;
  let tokens = 0;
  let failed = false;

  try {
    const response = await fetch("/chat-stream", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ messages: history }),
    });
    if (!response.ok) throw new Error(`HTTP ${response.status}: ${await response.text()}`);

    const reader = response.body.getReader();
    const decoder = new TextDecoder();
    let buffer = "";

    while (true) {
      const { done, value } = await reader.read();
      if (done) break;
      buffer += decoder.decode(value, { stream: true });

      // SSE events are separated by a blank line, not by "\n".
      let split;
      while ((split = buffer.indexOf("\n\n")) !== -1) {
        const raw = buffer.slice(0, split);
        buffer = buffer.slice(split + 2);
        if (!raw.startsWith("data: ")) continue;

        const frame = JSON.parse(raw.slice(6));
        if (frame.error) throw new Error(frame.error);
        if (frame.done) continue;
        if (frame.delta) {
          if (!firstTokenAt) {
            firstTokenAt = performance.now() - started;
            stats.textContent = `first token ${Math.round(firstTokenAt)} ms`;
          }
          tokens += 1;
          answer.textContent += frame.delta;
        }
      }
    }

    history.push({ role: "assistant", content: answer.textContent });
    const total = performance.now() - started;
    stats.textContent =
      `first token ${Math.round(firstTokenAt)} ms · ${tokens} deltas · ` +
      `total ${Math.round(total)} ms (streaming saved ${Math.round(total - firstTokenAt)} ms of waiting)`;
  } catch (error) {
    failed = true;
    answer.classList.add("error");
    answer.textContent = String(error);
    stats.textContent = "stream failed — check the uvicorn terminal";
  } finally {
    send.disabled = false;
    if (failed) history.pop();
  }
});
