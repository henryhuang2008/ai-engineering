Voice agent, terminal — run it

Speak into your microphone, get an answer out loud. In between, faster-whisper or Qwen transcribes, a LangGraph graph calls five MCP expense tools, and Qwen3-TTS speaks the reply. Everything runs in one terminal, and every stage prints its own timing.

The one-line model Record → transcribe → graph → speak, with the loop visible. This is the version to read before you let a framework hide it.

Setup

cd assets/examples/example-Voice-langgraph
uv sync
Copy-Item .env.example .env

Set both keys in your environment (reopen the terminal after setx): 

setx DEEPSEEK_API_KEY "sk-..."
setx DASHSCOPE_API_KEY "sk-..."

Edit .env: paste the Supabase connection string into SUPABASE_URI, then create the demo customer and copy the id it prints into CUSTOMER_ID. 

uv run python seed.py
# CUSTOMER_ID = 1cfa4b0d-...
# paste that line into .env

uv run python check.py

check.py verifies packages, keys, database tables, the MCP tool list and the configured speech engines. It should end with “Everything is ready”.

Run

uv run python smoke.py     # one measured turn, no microphone
uv run python main.py      # microphone loop

With main.py running, speak this, then press Enter:

“Create an expense for the team lunch today. It costs fifteen dollars.”

The microphone records until you press Enter; the recording is one turn. You should see a create_expense tool line, then hear: “Done — I’ve logged the team lunch for fifteen dollars under meals.”

To finish, say “exit”, “quit”, “close the program” or “that’s all”, then press Enter. Ctrl+C stops it at any point. Every turn is written to out/; the microphone side is 16 kHz, the Qwen reply is 24 kHz.

Switches

# .env
STT_PROVIDER=whisper      # local, free, 2.7–3.2× realtime
STT_PROVIDER=qwen         # qwen3-asr-flash, 20× realtime, audio leaves the machine
TTS_PROVIDER=qwen         # qwen3-tts-flash (default)
TTS_PROVIDER=elevenlabs   # optional, needs a usable voice in your account

Measured on the lab machine

Files worth reading

FileWhat it does
main.py the loop: record, transcribe, run the graph, speak
voice_utils.py STT and TTS providers, microphone, WAV files
assistant_graph.py the LangGraph agent and its streaming printer
mcps/…/db.py the five expense tools over SQLAlchemy
smoke.py one full turn with no microphone

If it fails

Qwen TTS returned 401: InvalidApiKey — Beijing and Singapore DashScope keys are different; set DASHSCOPE_REGION=singapore for an intl key. heard nothing — speak first, then press Enter. ELEVENLABS … 402 — the optional voice needs a paid plan or a voice in your own account; the Qwen default does not.
