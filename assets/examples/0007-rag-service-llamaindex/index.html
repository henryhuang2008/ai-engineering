README.md

# 0007 (LlamaIndex variant) — the same RAG service, framework-managed

This is the lesson 7 service rebuilt with **LlamaIndex** instead of the hand-written
LanceDB + LangChain path:

```
docs/  (reused from ../0007-rag-service/docs)
   │ parse.py: Docling -> HybridChunker -> contextualized text
   ▼
TextNode[] ── QwenEmbedding(text-embedding-v4) ──▶ LanceDBVectorStore
                                                      │
question ── VectorStoreIndex.as_query_engine(k=6) ────┘
   │
   ▼
DeepSeek (deepseek-flash) ──▶ answer + source_nodes
```

The corpus is the same three NimbusDesk documents, so both examples answer the
same five questions. The difference is who owns the pipeline:

| piece | main lab | this variant |
|---|---|---|
| parse/chunk | Docling `HybridChunker` | same |
| embedding | explicit Qwen batching | `QwenEmbedding(BaseEmbedding)` adapter |
| store | hand-written LanceDB table + FTS | `LanceDBVectorStore` |
| retrieval | explicit dense + BM25 + RRF | LlamaIndex `as_query_engine(k=6)` (dense) |
| answer | `ChatDeepSeek` + Pydantic + citations | `DeepSeek` + query engine; sources printed |
| incremental hashes | yes | `--rebuild` only |

If you need the explicit hybrid RRF and numbered citation validation, keep the
main lab. This variant shows how much of the plumbing LlamaIndex owns and what
you give up when you hand it over.

## The LlamaIndex pieces

```python
Settings.embed_model = QwenEmbedding()          # custom BaseEmbedding adapter
Settings.llm = DeepSeek(model="deepseek-flash", temperature=0, is_chat_model=True)

vector_store = LanceDBVectorStore(uri="index/lancedb", table_name="chunks_llamaindex")
index = VectorStoreIndex.from_vector_store(vector_store)
engine = index.as_query_engine(similarity_top_k=6, text_qa_template=TEXT_QA)
response = engine.query(question)
```

- `QwenEmbedding` wraps `text-embedding-v4` and preserves the `query` vs `document`
  split from lesson 6.
- `TextNode` carries the chunk text and metadata (`source`, `headings`, `pages`,
  `doc_hash`).
- `LanceDBVectorStore` persists nodes and vectors; `StorageContext` binds it to
  the index.
- `response.source_nodes` is the retrieved evidence, with scores.

## Files

| file | role |
|---|---|
| `common.py` | paths (shared corpus), Qwen constants, key checks |
| `qwen.py` | Qwen embeddings + `QwenEmbedding(BaseEmbedding)` |
| `parse.py` | Docling + HybridChunker, identical to the main lab |
| `ingest.py` | chunks → `TextNode` → Qwen → LanceDB |
| `ask.py` | `VectorStoreIndex` → query engine → answer + sources |
| `pyproject.toml` | uv project: llama-index-core, DeepSeek + LanceDB integrations, Docling |

## If it fails

- **`DASHSCOPE_API_KEY is not set`** / **`DEEPSEEK_API_KEY is not set`** — the
  scripts print the exact PowerShell lines and exit 1.
- **Docling download timeout** — set `HF_ENDPOINT=https://hf-mirror.com` and
  retry; the models are cached after the first success.
- **`no index found`** — run `uv run python ingest.py`.
- **`Table chunks_llamaindex doesn't exist yet`** — the index is empty or was
  deleted; re-run ingest.
- **Stale index after changing the embedding model** — run `ingest.py --rebuild`;
  vectors from different models are not comparable.
- **A dimension error from LanceDB** — the table was built with another embedder;
  rebuild it.

"""Shared paths, constants and key checks for the LlamaIndex variant.

The corpus is reused from the main lesson 7 lab, so both examples answer over
exactly the same three documents.
"""

from __future__ import annotations

import os
from pathlib import Path

HERE = Path(__file__).resolve().parent
DOCS_DIR = HERE.parent / "0007-rag-service" / "docs"
INDEX_DIR = HERE / "index"
DB_DIR = INDEX_DIR / "lancedb"
TABLE_NAME = "chunks_llamaindex"

EMBED_MODEL = "text-embedding-v4"
EMBED_DIM = 1024
EMBED_BATCH = 10
MAX_CHUNK_TOKENS = 512
DEFAULT_BASE_URL = "https://dashscope.aliyuncs.com/api/v1"

SUPPORTED_SUFFIXES = {".pdf", ".docx", ".pptx", ".xlsx", ".html", ".md"}

KEY_HELP = {
    "DASHSCOPE_API_KEY": (
        "indexing and search need Qwen text-embedding-v4",
        "https://bailian.console.alibabacloud.com/",
    ),
    "DEEPSEEK_API_KEY": (
        "the answer step needs DeepSeek",
        "https://platform.deepseek.com/api_keys",
    ),
}


class MissingKey(RuntimeError):
    """Raised with copy-pasteable setup instructions, never a stack trace."""


def missing_keys_message(names: list[str]) -> str:
    lines: list[str] = []
    for name in names:
        what, where = KEY_HELP[name]
        lines.append(f"{name} is not set - {what}.")
        lines.append(f'  PowerShell (this session):  $env:{name} = "sk-..."')
        lines.append(
            f'  PowerShell (persist):        setx {name} "sk-..."   # reopen the terminal'
        )
        lines.append(f"  Get a key:                  {where}")
        lines.append("")
    lines.append(
        "Optional, region-specific endpoint (if the default returns 401):\n"
        '  $env:DASHSCOPE_BASE_URL = "https://<your-region-host>/api/v1"'
    )
    return "\n".join(lines)


def require_keys(names: list[str]) -> None:
    missing = [name for name in names if not os.environ.get(name)]
    if missing:
        raise MissingKey(missing_keys_message(missing))


def docs() -> list[Path]:
    if not DOCS_DIR.exists():
        raise SystemExit(
            f"corpus not found: {DOCS_DIR}\n"
            "This variant reuses the documents from 0007-rag-service/docs."
        )
    return sorted(
        path
        for path in DOCS_DIR.rglob("*")
        if path.is_file() and path.suffix.lower() in SUPPORTED_SUFFIXES
    )

qwen.py

"""Qwen text-embedding-v4 for LlamaIndex, keeping the query/document split."""

from __future__ import annotations

import os
from typing import Any, Literal

import dashscope
from llama_index.core.embeddings import BaseEmbedding

from common import (
    DEFAULT_BASE_URL,
    EMBED_BATCH,
    EMBED_DIM,
    EMBED_MODEL,
    MissingKey,
    missing_keys_message,
)

TextType = Literal["document", "query"]


def _client() -> dashscope.Client:
    key = os.environ.get("DASHSCOPE_API_KEY")
    if not key:
        raise MissingKey(missing_keys_message(["DASHSCOPE_API_KEY"]))
    base_url = os.environ.get("DASHSCOPE_BASE_URL", DEFAULT_BASE_URL)
    return dashscope.Client(api_key=key, base_url=base_url)


def _embed(texts: list[str], text_type: TextType) -> list[list[float]]:
    if not texts:
        return []
    client = _client()
    vectors: list[list[float]] = []
    for start in range(0, len(texts), EMBED_BATCH):
        batch = texts[start : start + EMBED_BATCH]
        try:
            response = client.embeddings.create(
                model=EMBED_MODEL,
                input=batch,
                dimension=EMBED_DIM,
                text_type=text_type,
                output_type="dense",
            )
        except Exception as exc:
            raise SystemExit(f"Qwen embedding request failed: {exc}") from exc
        items = sorted(response.embeddings, key=lambda item: item.index)
        vectors.extend(item.embedding for item in items)
    if len(vectors) != len(texts):
        raise SystemExit(
            f"expected {len(texts)} vectors from Qwen, received {len(vectors)}"
        )
    return vectors


def embed_documents(texts: list[str]) -> list[list[float]]:
    return _embed(texts, "document")


def embed_query(text: str) -> list[float]:
    return _embed([text], "query")[0]


class QwenEmbedding(BaseEmbedding):
    """LlamaIndex adapter: batch documents, asymmetric query embedding."""

    model_name: str = EMBED_MODEL

    def _get_query_embedding(self, query: str) -> list[float]:
        return embed_query(query)

    async def _aget_query_embedding(self, query: str) -> list[float]:
        return embed_query(query)

    def _get_text_embedding(self, text: str) -> list[float]:
        return embed_documents([text])[0]

    def _get_text_embeddings(self, texts: list[str]) -> list[list[float]]:
        return embed_documents(texts)

    def _get_text_embedding_batch(
        self, texts: list[str], **kwargs: Any
    ) -> list[list[float]]:
        return embed_documents(texts)

parse.py

"""Docling -> HybridChunker, shared by ingest and --preview.

The parsing and chunking are intentionally identical to the main lesson 7 lab:
the framework changes, the chunk contract does not.
"""

from __future__ import annotations

import hashlib
from pathlib import Path

from common import MAX_CHUNK_TOKENS


def huggingface_hint(exc: Exception) -> SystemExit:
    text = str(exc)
    lower = text.lower()
    if (
        "huggingface.co" in lower
        or "couldn't connect" in lower
        or "connecttimeout" in lower
        or "winerror 10060" in lower
    ):
        return SystemExit(
            "Docling could not download its layout models.\n"
            "If huggingface.co is unreachable from your network, use a mirror and retry:\n"
            '  $env:HF_ENDPOINT = "https://hf-mirror.com"\n'
            "Models are cached after the first successful run."
        )
    return SystemExit(f"Docling failed: {exc}")


def sha256(path: Path) -> str:
    digest = hashlib.sha256()
    with path.open("rb") as handle:
        for block in iter(lambda: handle.read(1 << 20), b""):
            digest.update(block)
    return digest.hexdigest()


def parse_documents(paths: list[Path], ocr: bool = False) -> list[dict]:
    print(
        "  load    Docling (first run imports PyTorch and downloads models; be patient)",
        flush=True,
    )
    from docling.chunking import HybridChunker
    from docling.datamodel.base_models import InputFormat
    from docling.datamodel.pipeline_options import PdfPipelineOptions
    from docling.document_converter import DocumentConverter, PdfFormatOption

    print("  load    converter", flush=True)
    pipeline = PdfPipelineOptions()
    pipeline.do_ocr = ocr
    converter = DocumentConverter(
        format_options={InputFormat.PDF: PdfFormatOption(pipeline_options=pipeline)}
    )
    try:
        chunker = HybridChunker(max_tokens=MAX_CHUNK_TOKENS, merge_peers=True)
    except OSError as exc:
        raise huggingface_hint(exc) from None
    print(f"  load    chunker ({MAX_CHUNK_TOKENS}-token budget)", flush=True)

    records: list[dict] = []
    for path in paths:
        print(f"  parse   {path.name}", flush=True)
        try:
            result = converter.convert(str(path))
        except Exception as exc:
            raise huggingface_hint(exc) from None
        chunks = list(chunker.chunk(dl_doc=result.document))
        doc_hash = sha256(path)
        for position, chunk in enumerate(chunks):
            text = chunker.contextualize(chunk)
            headings = " > ".join(chunk.meta.headings or [])
            pages = sorted(
                {
                    prov.page_no
                    for item in (chunk.meta.doc_items or [])
                    for prov in (item.prov or [])
                }
            )
            records.append(
                {
                    "id": hashlib.sha1(
                        f"{path.name}|{position}|{text}".encode("utf-8")
                    ).hexdigest()[:12],
                    "text": text,
                    "source": path.name,
                    "headings": headings or "(no heading)",
                    "pages": ",".join(str(page) for page in pages),
                    "doc_hash": doc_hash,
                }
            )
        print(f"          {len(chunks)} chunks", flush=True)
    return records

ingest.py

"""Offline lane with LlamaIndex: Docling chunks -> Qwen vectors -> LanceDB.

    uv run python ingest.py --preview     # parse + chunk only, no key needed
    uv run python ingest.py               # embed and index
    uv run python ingest.py --rebuild     # delete the index and rebuild

The corpus is the three documents from the main lesson 7 lab, so both examples
answer the same questions over the same text.
"""

from __future__ import annotations

import argparse
import shutil
import statistics
import sys
import time

from llama_index.core import Settings, StorageContext, VectorStoreIndex
from llama_index.core.schema import TextNode
from llama_index.vector_stores.lancedb import LanceDBVectorStore

from common import (
    DB_DIR,
    TABLE_NAME,
    MissingKey,
    docs,
    missing_keys_message,
    require_keys,
)
from parse import parse_documents
from qwen import QwenEmbedding


def preview(records: list[dict], document_count: int, elapsed: float) -> None:
    lengths = [len(record["text"]) for record in records]
    print()
    print(f"{len(records)} chunks from {document_count} documents in {elapsed:.1f}s")
    if not lengths:
        return
    print(
        "characters per chunk: "
        f"min {min(lengths)}  median {int(statistics.median(lengths))}  max {max(lengths)}"
    )
    print("\nfirst three chunks as the embedder will see them:\n")
    for record in records[:3]:
        head = record["text"].replace("\n", " ")
        print(f"  [{record['id']}] {record['source']}  ({record['headings']})")
        print(f"    {head[:220]}{'...' if len(head) > 220 else ''}")
        print()


def main() -> int:
    parser = argparse.ArgumentParser(
        description=__doc__,
        formatter_class=argparse.RawDescriptionHelpFormatter,
    )
    parser.add_argument("--preview", action="store_true")
    parser.add_argument("--rebuild", action="store_true")
    parser.add_argument("--ocr", action="store_true")
    args = parser.parse_args()

    paths = docs()
    print(f"corpus: {len(paths)} documents in {paths[0].parent}")

    if args.preview:
        started = time.perf_counter()
        records = parse_documents(paths, ocr=args.ocr)
        preview(records, len(paths), time.perf_counter() - started)
        return 0

    if DB_DIR.exists() and any(DB_DIR.iterdir()) and not args.rebuild:
        print(f"index already exists in {DB_DIR}; use --rebuild to replace it.")
        return 0

    require_keys(["DASHSCOPE_API_KEY"])

    if args.rebuild:
        shutil.rmtree(DB_DIR, ignore_errors=True)

    Settings.embed_model = QwenEmbedding()

    started = time.perf_counter()
    records = parse_documents(paths, ocr=args.ocr)
    if not records:
        print("no chunks produced - is the corpus empty?", file=sys.stderr)
        return 1

    nodes = [
        TextNode(
            id_=record["id"],
            text=record["text"],
            metadata={
                "source": record["source"],
                "headings": record["headings"],
                "pages": record["pages"],
                "doc_hash": record["doc_hash"],
            },
        )
        for record in records
    ]

    vector_store = LanceDBVectorStore(
        uri=str(DB_DIR),
        table_name=TABLE_NAME,
        mode="overwrite",
    )
    storage = StorageContext.from_defaults(vector_store=vector_store)
    VectorStoreIndex(nodes, storage_context=storage, show_progress=True)

    print(
        f"\nindexed {len(nodes)} chunks from {len(paths)} documents "
        f"in {time.perf_counter() - started:.1f}s"
    )
    print(f"stored in {DB_DIR}")
    print("LlamaIndex embedded and persisted the nodes.")
    return 0


if __name__ == "__main__":
    try:
        raise SystemExit(main())
    except MissingKey as exc:
        print(exc, file=sys.stderr)
        raise SystemExit(1) from None
    except KeyboardInterrupt:
        print("\ninterrupted", file=sys.stderr)
        raise SystemExit(130) from None

ask.py

"""Online lane with LlamaIndex: question -> retriever -> DeepSeek -> answer.

    uv run python ask.py "How many seats does the Team plan include?"
    uv run python ask.py --show "What does E-311 mean?"

The query engine owns retrieval and synthesis. `response.source_nodes` is the
evidence that backed the answer; print it, because an answer without its sources
is not verifiable.
"""

from __future__ import annotations

import argparse
import os
import sys

from llama_index.core import Settings, VectorStoreIndex
from llama_index.core.prompts import PromptTemplate
from llama_index.llms.deepseek import DeepSeek
from llama_index.vector_stores.lancedb import LanceDBVectorStore

from common import (
    DB_DIR,
    TABLE_NAME,
    MissingKey,
    missing_keys_message,
    require_keys,
)
from qwen import QwenEmbedding

SYSTEM = """You answer questions about NimbusDesk using only the context provided.
If the context does not contain the answer, reply exactly: INSUFFICIENT_CONTEXT.
Do not use prior knowledge and do not invent a source."""

TEXT_QA = PromptTemplate(
    SYSTEM
    + """

Context:
{context_str}

Question: {query_str}
Answer:"""
)


def main() -> int:
    parser = argparse.ArgumentParser(
        description=__doc__,
        formatter_class=argparse.RawDescriptionHelpFormatter,
    )
    parser.add_argument("question", nargs="*")
    parser.add_argument("--k", type=int, default=6)
    parser.add_argument("--show", action="store_true")
    args = parser.parse_args()

    require_keys(["DASHSCOPE_API_KEY", "DEEPSEEK_API_KEY"])

    if not DB_DIR.exists():
        print("no index found - run `uv run python ingest.py` first", file=sys.stderr)
        return 1

    Settings.embed_model = QwenEmbedding()
    Settings.llm = DeepSeek(
        model="deepseek-flash",
        api_key=os.environ["DEEPSEEK_API_KEY"],
        api_base=os.environ.get("DEEPSEEK_BASE_URL", "https://api.deepseek.com"),
        temperature=0,
        is_chat_model=True,
    )

    vector_store = LanceDBVectorStore(uri=str(DB_DIR), table_name=TABLE_NAME)
    index = VectorStoreIndex.from_vector_store(vector_store)
    engine = index.as_query_engine(
        similarity_top_k=args.k,
        text_qa_template=TEXT_QA,
    )

    question = " ".join(args.question).strip()
    if not question:
        question = input("\nquestion> ").strip()
        if not question:
            return 0

    response = engine.query(question)

    print(f"\nquestion: {question}")
    print(f"\nanswer: {response.response}")
    print("\nsources:")
    for number, node in enumerate(response.source_nodes, start=1):
        meta = node.metadata
        print(
            f"  [{number}] {node.score:.4f}  "
            f"{meta.get('source', '?')}  {meta.get('headings', '(no heading)')}"
        )
        if args.show:
            print(f"       {node.text[:300].replace(chr(10), ' ')}...")

    if "INSUFFICIENT_CONTEXT" in str(response.response):
        print("\ninsufficient_context: True")
    return 0


if __name__ == "__main__":
    try:
        raise SystemExit(main())
    except MissingKey as exc:
        print(exc, file=sys.stderr)
        raise SystemExit(1) from None
    except KeyboardInterrupt:
        print("\ninterrupted", file=sys.stderr)
        raise SystemExit(130) from None
