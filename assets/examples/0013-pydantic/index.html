The schema is the contract

class Ticket(BaseModel):
    order_id: str = Field(description="Order id, for example A-1042")
    category: Literal["billing", "technical", "other"] = Field(
        description="billing for money, technical for product failures"
    )
    urgency: int = Field(ge=1, le=5, description="1 low, 5 urgent")
    wants_refund: bool = Field(description="True only if a refund is requested")
    summary: str = Field(description="One sentence, using only facts in the message")

with_structured_output converts this model to a JSON Schema, sends it as the function schema, and validates the returned arguments. Descriptions are instructions to the model; Literal makes a route impossible to misspell; ge/le become minimum/maximum in the schema.

# 0013 — Pydantic: make bad data fail at the boundary

Pydantic is the contract layer of an AI application. It validates the three places bad data enters:

- **inbound** — HTTP bodies, webhook payloads, form fields
- **outbound** — the JSON an LLM says it produced
- **configuration** — environment variables and `.env`

`basics.py` runs offline through models, constraints, validators, nested models, JSON Schema, `TypeAdapter`, and typed settings. `structured.py` makes one live **DeepSeek** call and parses the reply into a `Ticket` model.

## The five habits

1. **Put a model at every boundary.** A dict flowing through five functions is untyped; a `Ticket` is checked once and trusted after that.
2. **Use `Field` before a validator.** `ge`, `le`, `min_length`, `pattern` are declarative, appear in the JSON Schema, and are enforced by FastAPI and the model API. Write a validator only for business logic.
3. **Validate cross-field rules with `model_validator`.** `start <= end`, `discount < total`, `refund <= charge` — a single field cannot see the other.
4. **Use `pydantic-settings` for config.** `os.getenv` returns `str | None`; `BaseSettings` returns typed fields and fails at startup, not at the first request. `SecretStr` keeps keys out of logs.
5. **Let the schema be the contract with the model.** Descriptions on fields become instructions to the LLM. A `Literal` is how you make a route impossible to misspell.

## `model_validate` vs `**data`

Both construct a model; `model_validate` takes the dict as one value and supports options such as `strict=True`. Use `**data` in small scripts and `model_validate` at boundaries where the payload is already a dict from an API, queue, or file.

`model_dump()` returns Python objects; `model_dump_json()` returns a JSON string. `model_copy(update={...})` returns a copy with the updates applied — note that Pydantic does not revalidate those updates, so call `model_validate` on the dumped dict if the edit must be checked.

## If it fails

- **`DEEPSEEK_API_KEY is not set`** — only `structured.py` needs it. Copy the three lines the script prints, or create `.env` from `.env.example`.
- **`ValidationError` on a field you thought was valid** — read `error.errors()`: each item has `loc`, `msg`, and `type`. `loc` is the path, including list indexes and nested models.
- **`EmailStr` import error** — `email-validator` is missing. It is in `pyproject.toml`; run `uv sync`.
- **The model returns the wrong shape** — the provider chose a different tool. Check that `method="function_calling"` is supported by the model, and keep the schema small. Descriptions are part of the prompt.
- **`model_validate` rejects a dict that `Model(**dict)` accepted** — they should agree; if not, you are probably passing a non-dict or using `strict=True` somewhere. Print `type(payload)` first.

basics.py

"""Pydantic, from the first model to validated settings - all offline.

Run from this folder:

    uv sync
    uv run python basics.py

No API key is needed. `structured.py` is the live DeepSeek half.
"""

from __future__ import annotations

from dataclasses import dataclass
from typing import Literal

from pydantic import (
    BaseModel,
    ConfigDict,
    EmailStr,
    Field,
    SecretStr,
    TypeAdapter,
    ValidationError,
    field_validator,
    model_validator,
)
from pydantic_settings import BaseSettings, SettingsConfigDict


def heading(text: str) -> None:
    print(f"\n== {text} " + "=" * max(0, 58 - len(text)))


# --- 1. a dataclass stores, a model checks ---------------------------------


@dataclass
class DataUser:
    name: str
    age: int


class User(BaseModel):
    name: str = Field(min_length=1, max_length=50)
    age: int = Field(ge=0, le=120)
    email: EmailStr | None = None


heading("1. dataclass vs BaseModel")
raw = DataUser(name="Alice", age="not a number")  # type: ignore[arg-type]
print(f"dataclass accepted age={raw.age!r} ({type(raw.age).__name__})")

try:
    User(name="Alice", age="not a number")
except ValidationError as error:
    print(f"pydantic rejected: {error.errors()[0]['msg']}")

coerced = User(name="Alice", age="25")
print(f'pydantic coerced "25" -> {coerced.age!r} ({type(coerced.age).__name__})')


# --- 2. required, optional, defaults ---------------------------------------


heading("2. required, optional, defaults")
print(f"only required fields: {User(name='Bob', age=41).model_dump()}")
print(f"nullable field:       {User(name='Bob', age=41, email=None).email}")

try:
    User(name="", age=41)
except ValidationError as error:
    detail = error.errors()[0]
    print(f"empty name -> loc={detail['loc']} type={detail['type']}")

try:
    User(name="Bob", age=41, email="not-an-email")
except ValidationError as error:
    print(f"bad email -> {error.errors()[0]['msg']}")


# --- 3. constraints are data, not prose ------------------------------------


class Signup(BaseModel):
    username: str = Field(min_length=3, max_length=20)
    plan: Literal["free", "team", "enterprise"]
    seats: int = Field(default=1, ge=1, le=500)

    @field_validator("username")
    @classmethod
    def no_spaces(cls, value: str) -> str:
        if " " in value:
            raise ValueError("username cannot contain spaces")
        return value.lower()


heading("3. constraints and a field validator")
print(Signup(username="AliceDev", plan="team", seats=5).model_dump())
try:
    Signup(username="Alice Dev", plan="team")
except ValidationError as error:
    print(f"custom validator -> {error.errors()[0]['msg']}")


class DateRange(BaseModel):
    start: int
    end: int

    @model_validator(mode="after")
    def ordered(self) -> "DateRange":
        if self.start > self.end:
            raise ValueError("start must be <= end")
        return self


heading("3b. a model validator sees both fields")
print(DateRange(start=1, end=9).model_dump())
try:
    DateRange(start=9, end=1)
except ValidationError as error:
    print(f"cross-field -> {error.errors()[0]['msg']}")


# --- 4. nested models and lists --------------------------------------------


class Address(BaseModel):
    city: str
    country: str


class Customer(BaseModel):
    name: str
    address: Address


class LineItem(BaseModel):
    sku: str
    quantity: int = Field(ge=1)
    unit_price: float = Field(ge=0)


class Order(BaseModel):
    order_id: str = Field(pattern=r"^ORD-\d+$")
    customer: Customer
    items: list[LineItem]
    note: str | None = None


heading("4. nested models, lists, serialization")
payload = {
    "order_id": "ORD-1042",
    "customer": {
        "name": "Dana",
        "address": {"city": "Amsterdam", "country": "NL"},
    },
    "items": [
        {"sku": "WIDGET", "quantity": 2, "unit_price": 29.99},
        {"sku": "GADGET", "quantity": 1, "unit_price": 49.99},
    ],
}
order = Order.model_validate(payload)
print(f"city:      {order.customer.address.city}")
print(f"first:     {order.items[0].sku} x{order.items[0].quantity}")
print(f"dict:      {order.model_dump()['items'][1]}")
print(f"json head: {order.model_dump_json()[:80]}...")

try:
    Order.model_validate({**payload, "order_id": "1042"})
except ValidationError as error:
    print(f"pattern -> {error.errors()[0]['type']}")


# --- 5. JSON Schema: the bridge to tools and LLMs --------------------------


heading("5. JSON Schema")
schema = Order.model_json_schema()
print(f"required:   {schema['required']}")
print(f"properties: {sorted(schema['properties'])}")
print(f"nested:     {sorted(schema['$defs'])}")


# --- 6. TypeAdapter: validate a list without a wrapper model ---------------


heading("6. TypeAdapter for a bare list")
items = TypeAdapter(list[LineItem]).validate_python(
    [{"sku": "WIDGET", "quantity": 2, "unit_price": 29.99}]
)
print(f"{len(items)} item(s), first sku={items[0].sku}")


# --- 7. typed settings: fail at boot, not at request ----------------------


class DemoSettings(BaseSettings):
    model_config = SettingsConfigDict(
        env_prefix="DEMO_", env_file=".env", extra="ignore"
    )

    api_key: SecretStr = SecretStr("not-set")
    max_retries: int = Field(default=2, ge=0, le=5)
    debug: bool = False


heading("7. pydantic-settings")
settings = DemoSettings()
print(f"api_key:     {settings.api_key}  (masked)")
print(f"max_retries: {settings.max_retries}")
print(f"debug:       {settings.debug}")
print("values come from DEMO_API_KEY / DEMO_MAX_RETRIES / DEMO_DEBUG or defaults")


# --- 8. strict mode is available, but not the default ----------------------


class StrictUser(BaseModel):
    model_config = ConfigDict(strict=True)

    name: str
    age: int


heading("8. strict mode")
try:
    StrictUser(name="Alice", age="25")  # type: ignore[arg-type]
except ValidationError as error:
    print(f"strict rejects the string: {error.errors()[0]['msg']}")

print("\ndone: models, fields, validators, nesting, schema, settings.")

structured.py

"""Live DeepSeek extraction with a Pydantic schema.

Run from this folder:

    uv sync
    $env:DEEPSEEK_API_KEY = "sk-..."
    uv run python structured.py

The model is asked for a `Ticket`; LangChain turns the Pydantic JSON Schema into
a tool schema, DeepSeek calls it, and Pydantic validates the arguments before
you ever touch the object.
"""

from __future__ import annotations

import json
import sys
from typing import Literal

from langchain_core.messages import HumanMessage, SystemMessage
from pydantic import BaseModel, Field, ValidationError

from common import build_model

TICKET_TEXT = (
    "Order A-1042 was charged twice this month. "
    "I want a refund today, please. My email is dana@example.com."
)


class Ticket(BaseModel):
    """What we want out of a support message."""

    order_id: str = Field(description="Order id, for example A-1042")
    category: Literal["billing", "technical", "other"] = Field(
        description="billing for money, technical for product failures"
    )
    urgency: int = Field(ge=1, le=5, description="1 low, 5 urgent")
    wants_refund: bool = Field(description="True only if a refund is requested")
    summary: str = Field(description="One sentence, using only facts in the message")


SYSTEM = "Extract the support ticket. Use only facts present in the message."


def main() -> int:
    try:
        model = build_model()
    except RuntimeError as error:
        print(f"error: {error}", file=sys.stderr)
        return 1

    schema = Ticket.model_json_schema()
    print("ticket schema:")
    print(json.dumps(schema, indent=2))
    print(f"\nrequired fields: {schema['required']}\n")

    extractor = model.with_structured_output(Ticket, method="function_calling")
    try:
        ticket = extractor.invoke(
            [SystemMessage(content=SYSTEM), HumanMessage(content=TICKET_TEXT)]
        )
    except Exception as error:  # noqa: BLE001 - show the provider error, keep exit 1
        print(f"error: {type(error).__name__}: {error}", file=sys.stderr)
        print("check DEEPSEEK_API_KEY, balance, and network access.", file=sys.stderr)
        return 1

    print(f"type:    {type(ticket).__name__} (validated instance)")
    print(f"order:   {ticket.order_id}")
    print(f"route:   {ticket.category}")
    print(f"urgency: {ticket.urgency}")
    print(f"refund:  {ticket.wants_refund}")
    print(f"summary: {ticket.summary}")
    print("\nas JSON:")
    print(ticket.model_dump_json(indent=2))
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

common.py

"""One ChatDeepSeek builder for the live structured-output script.

`basics.py` needs no key. Only `structured.py` does:

  PowerShell (this session):  $env:DEEPSEEK_API_KEY = "sk-..."
  .env (this folder):         DEEPSEEK_API_KEY=sk-...

Get a key at https://platform.deepseek.com/api_keys. No key -> a clear message
and exit 1, never a guess.
"""

from __future__ import annotations

import os

from dotenv import load_dotenv
from langchain_deepseek import ChatDeepSeek

load_dotenv()

MODEL = os.getenv("DEEPSEEK_MODEL", "deepseek-flash")
BASE_URL = os.getenv("DEEPSEEK_BASE_URL", "https://api.deepseek.com")


def missing_key_message() -> str:
    return (
        "DEEPSEEK_API_KEY is not set.\n"
        '  PowerShell (this session):  $env:DEEPSEEK_API_KEY = "sk-..."\n'
        "  .env (this folder):         DEEPSEEK_API_KEY=sk-...\n"
        "  Get a key:                  https://platform.deepseek.com/api_keys"
    )


def build_model() -> ChatDeepSeek:
    key = os.getenv("DEEPSEEK_API_KEY")
    if not key:
        raise RuntimeError(missing_key_message())

    return ChatDeepSeek(
        model=MODEL,
        api_key=key,
        api_base=BASE_URL,
        temperature=0,
        max_retries=2,
        timeout=60,
        extra_body={"thinking": {"type": "disabled"}},
    )
