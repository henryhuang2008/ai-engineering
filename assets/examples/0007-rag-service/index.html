README.md

# 0007 — The RAG service: index once, answer every query

Lesson 6 drew the pipeline. This is the first real build of it: a corpus of three
documents, an offline lane that turns them into a LanceDB table, and an online lane
that answers questions from that table with citations.

**Two parts, two commands.**

| part | lanes | command | what it produces |
|---|---|---|---|
| offline | stages 1–4 | `uv run python ingest.py` | chunks, 1024-d vectors and a BM25 index in one LanceDB table |
| online | stages 5–8 | `uv run python ask.py "..."` | a grounded answer with validated citations |

There is no fake model and no cached answer. The embedder is **Qwen
`text-embedding-v4`**, the generator is **DeepSeek `deepseek-flash`**, and the store is
**LanceDB** because it ships BM25 and hybrid search on the same table as the vectors.

---

## Keys

Two vendors, because DeepSeek has no embeddings endpoint. Both are needed for a full
run; `--preview` needs neither.

```powershell
$env:DASHSCOPE_API_KEY = "sk-..."     # Qwen embeddings
$env:DEEPSEEK_API_KEY = "sk-..."      # DeepSeek generation
```

Persist them with `setx` and reopen the terminal. No key prints these commands and
exits 1.

- Qwen key: <https://bailian.console.alibabacloud.com/>
- DeepSeek key: <https://platform.deepseek.com/api_keys>

Keys are region-specific. If the embedding call returns 401, set the endpoint from
your DashScope console:

```powershell
$env:DASHSCOPE_BASE_URL = "https://<your-region-host>/api/v1"
```

## Run

```powershell
cd assets\examples\0007-rag-service
uv sync                                  # first run is large: Docling + PyTorch
uv run python ingest.py --preview        # parse + chunk, no API key, no index
uv run python ingest.py                  # embed and index (writes index/lancedb)
uv run python ask.py "How many seats does the Team plan include?"
```

`uv run python ask.py` with no question starts a prompt loop. `--show` prints the
retrieved evidence; `--k` changes how many chunks reach the model (default 6);
`--rerank` adds a cross-encoder, off by default so you can measure the difference.
`--ocr` turns OCR on for scanned PDFs (off by default; it roughly doubles parse time).

### First run downloads models

Docling downloads its layout models once (a few hundred MB) and caches them. If
`huggingface.co` is unreachable, use a mirror:

```powershell
$env:HF_ENDPOINT = "https://hf-mirror.com"
```

The lab prints this hint itself when the download fails.

## The corpus

`docs/` holds three formats on purpose, so the parse stage has real work to do:

| file | format | why it is here |
|---|---|---|
| `nimbusdesk-handbook.pdf` | PDF | headings, page anchors, a troubleshooting table |
| `nimbusdesk-plans.docx` | DOCX | a real table: seats, storage, API limits, SSO |
| `release-notes.md` | Markdown | dated entries; exact error codes and version facts |

NimbusDesk is fictional, but the facts are specific and checkable: 25 Team seats,
E-311, a 14-day refund window, SAML on Business only.

That first **35 seconds is Docling**, not a hang: importing PyTorch plus running the

Inspect this before spending tokens. If a chunk is a single heading, or a table is
split in half, fix the corpus or the chunk budget — not the prompt.

## What a good answer looks like

The ids, scores and wording vary between runs. The facts and the shape should not:

```
question: How many seats does the Team plan include?
retrieved 6 chunks (hybrid, RRF)
  [1] 0.0xxx  nimbusdesk-plans.docx  NimbusDesk plans and limits
  ...

answer: The Team plan includes 25 seats [1].
insufficient_context: False
citations:
  [1] nimbusdesk-plans.docx  chunk <id>
```

Five questions to try, with the fact to check:

| question | must contain | best source |
|---|---|---|
| How many seats does the Team plan include? | 25 | plans DOCX |
| What does E-311 mean? | mailbox storage quota | handbook §7 |
| How long do I have to request a refund? | 14 days | handbook §6 |
| Is SAML SSO available on Team? | no, Business only | plans DOCX / handbook §3 |
| What happens to deleted conversations? | recoverable 30 days, then purged | handbook §4 |

Ask something the corpus does **not** answer ("What is the SLA for the mobile app?")
and the `insufficient_context` flag is the thing to watch, not the prose.

## How it maps to lesson 6

| stage | in the code |
|---|---|
| 1 parse | `DocumentConverter().convert(path)` — Docling reads order, headings, tables |
| 2 chunk | `HybridChunker(max_tokens=512, merge_peers=True)`; `contextualize()` prepends the heading path |
| 3 embed + index | `text_type="document"`, 1024 dims, batches of 10; BM25 index on the same text |
| 4 store | one LanceDB table: id, text, source, headings, pages, doc_hash, vector |
| 5 prepare query | `text_type="query"`, same model and dimension |
| 6 retrieve | one hybrid query; dense + BM25 fused by `RRFReranker` |
| 7 rerank | `--rerank` swaps in `CrossEncoderReranker`; off by default |
| 8 generate | `ChatDeepSeek` + `with_structured_output(Answer, method="function_calling")`; citation numbers checked against the retrieved set |

Incremental indexing is real, not a TODO: each row stores the document's sha256, an
unchanged file is skipped, and a changed file has its rows deleted before the new ones
are added. Delete `index/` to start clean, or pass `--rebuild`.

## Files

| file | role |
|---|---|
| `common.py` | paths, model name, dimension, key checks |
| `qwen.py` | `text-embedding-v4` wrapper: batching and `query`/`document` |
| `store.py` | LanceDB schema, FTS index, hybrid query |
| `ingest.py` | offline lane + `--preview` |
| `ask.py` | online lane + citation validation |
| `docs/` | the corpus |
| `index/` | generated LanceDB database (not source) |

## Notes and limits

- **Batch limit:** Qwen accepts at most 10 texts per embedding request. `qwen.py`
  batches for you; do not remove it.
- **Dimension is fixed:** 1024 is written into the table schema. Changing the model or
  the dimension means rebuilding the index, not migrating it.
- **Chunk budget:** 512 tokens. The DOCX table lands as one 990-character chunk because
  it is short; longer tables are repeated per chunk with their header.
- **No vector index:** 15 rows do not need one. LanceDB brute-forces small tables; an
  IVF/HNSW index is an operational step for a much larger corpus, not part of this lab.
- **No rerank by default:** stage 7 is a flag, not a default, so the difference is
  measurable rather than assumed.
- **Cost:** embedding 15 chunks and a handful of queries is well under a cent at
  `text-embedding-v4` list price. Generation dominates the bill.

ingest.py

"""Part 1, offline: documents -> chunks -> vectors + BM25 -> one LanceDB table.

Stages 1-4 of lesson 6, in one command:

    uv run python ingest.py --preview     # parse + chunk only, no API key needed
    uv run python ingest.py               # embed and index
    uv run python ingest.py --rebuild     # ignore hashes, rebuild everything
    uv run python ingest.py --preview --ocr   # scanned PDFs only; OCR is slow

The first run downloads Docling's layout models and a tokenizer (a few hundred
MB, once) and the first preview takes roughly 30-60 s on a CPU. OCR is off by
default because born-digital PDFs already carry text; turn it on with --ocr
when the pages are scans.

Incremental by design: a document whose sha256 has not changed is skipped, and
a changed document has its old rows deleted before the new ones are added. The
document hash is stored in the table, so there is no manifest to drift.
"""

from __future__ import annotations

import argparse
import hashlib
import statistics
import sys
import time
from pathlib import Path

from common import (
    MAX_CHUNK_TOKENS,
    MissingKey,
    TABLE_NAME,
    docs,
    require_keys,
)
from store import (
    Chunk,
    build_fts,
    connect,
    create_table,
    delete_source,
    existing_hashes,
    open_table,
    table_names,
)


def huggingface_hint(exc: Exception) -> SystemExit:
    text = str(exc)
    if "huggingface.co" in text or "couldn't connect" in text.lower():
        return SystemExit(
            "Docling could not download its layout models.\n"
            "If huggingface.co is unreachable from your network, use a mirror and retry:\n"
            '  $env:HF_ENDPOINT = "https://hf-mirror.com"\n'
            "Models are cached after the first successful run."
        )
    return SystemExit(f"Docling failed: {exc}")


def sha256(path: Path) -> str:
    digest = hashlib.sha256()
    with path.open("rb") as handle:
        for block in iter(lambda: handle.read(1 << 20), b""):
            digest.update(block)
    return digest.hexdigest()


def parse_documents(paths: list[Path], ocr: bool = False) -> list[dict]:
    """Docling -> HybridChunker. Structure first, token budget second."""
    print(
        "  load    Docling (first run imports PyTorch and downloads models; be patient)",
        flush=True,
    )
    from docling.chunking import HybridChunker
    from docling.datamodel.base_models import InputFormat
    from docling.datamodel.pipeline_options import PdfPipelineOptions
    from docling.document_converter import DocumentConverter, PdfFormatOption

    print("  load    converter", flush=True)
    pipeline = PdfPipelineOptions()
    # Born-digital PDFs already carry text; OCR is the slow path and is off
    # by default. Scanned pages need `--ocr`.
    pipeline.do_ocr = ocr
    converter = DocumentConverter(
        format_options={InputFormat.PDF: PdfFormatOption(pipeline_options=pipeline)}
    )
    try:
        chunker = HybridChunker(max_tokens=MAX_CHUNK_TOKENS, merge_peers=True)
    except OSError as exc:
        raise huggingface_hint(exc) from None
    print("  load    chunker (512-token budget)", flush=True)
    records: list[dict] = []

    for path in paths:
        print(f"  parse   {path.name}", flush=True)
        try:
            result = converter.convert(str(path))
        except OSError as exc:
            raise huggingface_hint(exc) from None
        chunks = list(chunker.chunk(dl_doc=result.document))
        doc_hash = sha256(path)
        for position, chunk in enumerate(chunks):
            # contextualize() prepends the heading path, so a chunk about
            # refunds still knows it is under "Refunds and billing corrections".
            text = chunker.contextualize(chunk)
            headings = " > ".join(chunk.meta.headings or [])
            pages = sorted(
                {
                    prov.page_no
                    for item in (chunk.meta.doc_items or [])
                    for prov in (item.prov or [])
                }
            )
            records.append(
                {
                    "id": hashlib.sha1(
                        f"{path.name}|{position}|{text}".encode("utf-8")
                    ).hexdigest()[:12],
                    "text": text,
                    "source": path.name,
                    "headings": headings or "(no heading)",
                    "pages": ",".join(str(page) for page in pages),
                    "doc_hash": doc_hash,
                }
            )
        print(f"          {len(chunks)} chunks", flush=True)

    return records


def preview(records: list[dict], document_count: int, elapsed: float) -> None:
    lengths = [len(record["text"]) for record in records]
    print()
    print(f"{len(records)} chunks from {document_count} documents in {elapsed:.1f}s")
    if not lengths:
        return
    print(
        "characters per chunk: "
        f"min {min(lengths)}  median {int(statistics.median(lengths))}  max {max(lengths)}"
    )
    print("\nfirst three chunks as the embedder will see them:\n")
    for record in records[:3]:
        head = record["text"].replace("\n", " ")
        print(f"  [{record['id']}] {record['source']}  ({record['headings']})")
        print(f"    {head[:220]}{'...' if len(head) > 220 else ''}")
        print()


def main() -> int:
    parser = argparse.ArgumentParser(
        description=__doc__,
        formatter_class=argparse.RawDescriptionHelpFormatter,
    )
    parser.add_argument(
        "--preview",
        action="store_true",
        help="parse and chunk only; print what would be embedded",
    )
    parser.add_argument(
        "--rebuild",
        action="store_true",
        help="ignore document hashes and re-index everything",
    )
    parser.add_argument(
        "--ocr",
        action="store_true",
        help="run OCR (needed for scanned PDFs; slower, off by default)",
    )
    args = parser.parse_args()

    paths = docs()
    print(f"corpus: {len(paths)} documents in {paths[0].parent}")

    if args.preview:
        started = time.perf_counter()
        records = parse_documents(paths, ocr=args.ocr)
        preview(records, len(paths), time.perf_counter() - started)
        return 0

    db = connect()
    fresh = args.rebuild or TABLE_NAME not in table_names(db)
    table = None
    if fresh:
        todo = paths
    else:
        table = open_table(db)
        known = existing_hashes(table)
        current = {path.name: sha256(path) for path in paths}
        todo = [path for path in paths if known.get(path.name) != current[path.name]]

    if not todo:
        if table is None:
            print("no documents found in docs/", file=sys.stderr)
            return 1
        build_fts(table)
        print(f"nothing changed; {table.count_rows()} chunks already indexed")
        return 0

    require_keys(["DASHSCOPE_API_KEY"])
    if fresh:
        table = create_table(db, [])

    started = time.perf_counter()
    records = parse_documents(todo, ocr=args.ocr)
    if not records:
        print("no chunks produced - is the corpus empty?", file=sys.stderr)
        return 1

    print(f"\n  embed   {len(records)} chunks with Qwen text-embedding-v4")
    from qwen import embed_documents

    vectors = embed_documents([record["text"] for record in records])
    rows = [Chunk(**record, vector=vector) for record, vector in zip(records, vectors)]

    if not fresh:
        for path in todo:
            delete_source(table, path.name)
    table.add(rows)
    build_fts(table)

    print(
        f"\nindexed {len(rows)} chunks from {len(todo)} documents "
        f"({len(paths) - len(todo)} unchanged) in {time.perf_counter() - started:.1f}s; "
        f"table now holds {table.count_rows()}"
    )
    return 0


if __name__ == "__main__":
    try:
        raise SystemExit(main())
    except MissingKey as exc:
        print(exc, file=sys.stderr)
        raise SystemExit(1) from None
    except KeyboardInterrupt:
        print("\ninterrupted", file=sys.stderr)
        raise SystemExit(130) from None

ask.py

"""Part 2, online: question -> two representations -> hybrid search -> answer.

Stages 5-8 of lesson 6:

  5 prepare  embed the question with text_type="query"; BM25 uses the same text
  6 retrieve one hybrid query: dense + BM25, fused by reciprocal rank fusion
  7 rerank   optional cross-encoder (--rerank); off by default so you can compare
  8 generate ChatDeepSeek, forced into a pydantic Answer, citations validated

Run one question:

    uv run python ask.py "How many seats does the Team plan include?"

Or leave the question off for a prompt loop. `--show` prints the evidence that
was retrieved, which is the first thing to inspect when an answer is wrong.
"""

from __future__ import annotations

import argparse
import sys

from pydantic import BaseModel, Field

from common import TABLE_NAME, MissingKey, require_keys
from qwen import embed_query
from store import connect, hybrid_search, open_table, table_names

SYSTEM = """You answer questions about NimbusDesk using only the evidence provided.

Rules:
- Every factual claim must come from the evidence, not from prior knowledge.
- Cite the evidence numbers you used in square brackets, for example [1] or [2, 4].
- If the evidence does not contain the answer, say so plainly and set
  insufficient_context to true. Do not guess and do not invent a source."""


class Answer(BaseModel):
    answer: str = Field(description="The answer, grounded only in the evidence.")
    citations: list[int] = Field(
        default_factory=list,
        description="Evidence numbers used, for example [1, 3].",
    )
    insufficient_context: bool = Field(
        description="True when the evidence does not answer the question.",
    )


def format_evidence(rows: list[dict]) -> str:
    blocks = []
    for number, row in enumerate(rows, start=1):
        heading = row.get("headings") or "(no heading)"
        blocks.append(f"[{number}] {row['source']} - {heading}\n{row['text']}")
    return "\n\n".join(blocks)


def answer_question(question: str, k: int, rerank: bool, show: bool) -> None:
    db = connect()
    if TABLE_NAME not in table_names(db):
        raise SystemExit("no index found - run `uv run python ingest.py` first")
    table = open_table(db)

    vector = embed_query(question)
    rows = hybrid_search(table, question, vector, k=k, rerank=rerank)
    if not rows:
        print("no chunks retrieved - is the index empty?")
        return

    print(f"\nquestion: {question}")
    print(f"retrieved {len(rows)} chunks (hybrid, {'cross-encoder' if rerank else 'RRF'})")
    for number, row in enumerate(rows, start=1):
        score = row.get("_relevance_score")
        score_text = f"{score:.4f}" if isinstance(score, float) else "-"
        print(f"  [{number}] {score_text}  {row['source']}  {row['headings']}")

    if show:
        print("\n--- evidence ---")
        print(format_evidence(rows))
        print("--- end evidence ---")

    from langchain_core.messages import HumanMessage, SystemMessage
    from langchain_deepseek import ChatDeepSeek

    model = ChatDeepSeek(
        model="deepseek-flash",
        temperature=0,
        extra_body={"thinking": {"type": "disabled"}},
    )
    structured = model.with_structured_output(Answer, method="function_calling")
    message = (
        f"Question: {question}\n\n"
        f"Evidence:\n\n{format_evidence(rows)}\n\n"
        "Answer from the evidence above."
    )
    result = structured.invoke(
        [SystemMessage(content=SYSTEM), HumanMessage(content=message)]
    )

    valid = [number for number in result.citations if 1 <= number <= len(rows)]
    if len(valid) != len(result.citations):
        bad = sorted({n for n in result.citations if not 1 <= n <= len(rows)})
        print(f"\nwarning: dropped citations outside the evidence set: {bad}")
    if not valid and not result.insufficient_context:
        print("\nwarning: answer has no citations and does not flag insufficient context")

    print(f"\nanswer: {result.answer}")
    print(f"insufficient_context: {result.insufficient_context}")
    if valid:
        print("citations:")
        for number in dict.fromkeys(valid):
            row = rows[number - 1]
            print(f"  [{number}] {row['source']}  chunk {row['id']}")


def main() -> int:
    parser = argparse.ArgumentParser(
        description=__doc__,
        formatter_class=argparse.RawDescriptionHelpFormatter,
    )
    parser.add_argument("question", nargs="*", help="one question; omit for a prompt loop")
    parser.add_argument("--k", type=int, default=6, help="chunks passed to the model (default 6)")
    parser.add_argument(
        "--rerank",
        action="store_true",
        help="add a cross-encoder reranker (downloads a model on first use)",
    )
    parser.add_argument("--show", action="store_true", help="print the retrieved evidence")
    args = parser.parse_args()

    require_keys(["DASHSCOPE_API_KEY", "DEEPSEEK_API_KEY"])

    if args.question:
        answer_question(" ".join(args.question), args.k, args.rerank, args.show)
        return 0

    while True:
        try:
            question = input("\nquestion> ").strip()
        except (EOFError, KeyboardInterrupt):
            print()
            return 0
        if not question or question.lower() in {"exit", "quit"}:
            return 0
        answer_question(question, args.k, args.rerank, args.show)


if __name__ == "__main__":
    try:
        raise SystemExit(main())
    except MissingKey as exc:
        print(exc, file=sys.stderr)
        raise SystemExit(1) from None
    except KeyboardInterrupt:
        print("\ninterrupted", file=sys.stderr)
        raise SystemExit(130) from None

qwen.py

"""Qwen text-embedding-v4, with the query/document split lesson 6 asks for.

DeepSeek has no embeddings endpoint. That is not a problem: generation and
embedding are independent, and this file is the only place that knows the
embedder is Qwen.

Two details are easy to miss and expensive to get wrong:
  * the same model must be used at index time and query time;
  * the API embeds at most 10 texts per request, so batching is explicit.
"""

from __future__ import annotations

import os
from typing import Literal

import dashscope

from common import (
    DEFAULT_BASE_URL,
    EMBED_BATCH,
    EMBED_DIM,
    EMBED_MODEL,
    MissingKey,
    missing_keys_message,
)

TextType = Literal["document", "query"]


def _client() -> dashscope.Client:
    key = os.environ.get("DASHSCOPE_API_KEY")
    if not key:
        raise MissingKey(missing_keys_message(["DASHSCOPE_API_KEY"]))
    base_url = os.environ.get("DASHSCOPE_BASE_URL", DEFAULT_BASE_URL)
    return dashscope.Client(api_key=key, base_url=base_url)


def _embed(texts: list[str], text_type: TextType) -> list[list[float]]:
    if not texts:
        return []
    client = _client()
    vectors: list[list[float]] = []
    for start in range(0, len(texts), EMBED_BATCH):
        batch = texts[start : start + EMBED_BATCH]
        try:
            response = client.embeddings.create(
                model=EMBED_MODEL,
                input=batch,
                dimension=EMBED_DIM,
                text_type=text_type,
                output_type="dense",
            )
        except Exception as exc:  # network, auth, quota - show the reason
            raise SystemExit(f"Qwen embedding request failed: {exc}") from exc
        items = sorted(response.embeddings, key=lambda item: item.index)
        vectors.extend(item.embedding for item in items)
    if len(vectors) != len(texts):
        raise SystemExit(
            f"expected {len(texts)} vectors from Qwen, received {len(vectors)}"
        )
    return vectors


def embed_documents(texts: list[str]) -> list[list[float]]:
    """Index-time embedding: text_type='document'."""
    return _embed(texts, "document")


def embed_query(text: str) -> list[float]:
    """Query-time embedding: text_type='query', same model, same dimension."""
    return _embed([text], "query")[0]

store.py

"""LanceDB: one table for rows, vectors and the BM25 index.

A row is a chunk. The vector column feeds the dense half of a hybrid query;
the FTS index on `text` feeds the BM25 half. Both live in the same table, so a
filter applies to both and chunk ids never have to be joined by hand.
"""

from __future__ import annotations

from typing import Any

import lancedb
from lancedb.index import FTS
from lancedb.pydantic import LanceModel, Vector
from lancedb.rerankers import RRFReranker

from common import DB_DIR, EMBED_DIM, TABLE_NAME


class Chunk(LanceModel):
    id: str
    text: str
    source: str
    headings: str
    pages: str
    doc_hash: str
    vector: Vector(EMBED_DIM)


def connect() -> lancedb.DBConnection:
    DB_DIR.mkdir(parents=True, exist_ok=True)
    return lancedb.connect(str(DB_DIR))


def table_names(db: lancedb.DBConnection) -> list[str]:
    return list(db.table_names())


def open_table(db: lancedb.DBConnection) -> lancedb.table.Table:
    return db.open_table(TABLE_NAME)


def create_table(db: lancedb.DBConnection, rows: list[Chunk]) -> lancedb.table.Table:
    table = db.create_table(TABLE_NAME, schema=Chunk, mode="overwrite")
    if rows:
        table.add(rows)
    return table


def delete_source(table: lancedb.table.Table, source: str) -> None:
    escaped = source.replace("'", "''")
    table.delete(f"source = '{escaped}'")


def build_fts(table: lancedb.table.Table) -> None:
    """BM25 index. These analyser settings are fixed here and assumed at query time."""
    table.create_index(
        "text",
        config=FTS(
            language="English",
            stem=True,
            remove_stop_words=True,
            ascii_folding=True,
        ),
        replace=True,
    )


def existing_hashes(table: lancedb.table.Table) -> dict[str, str]:
    """source -> doc_hash, read back from the table itself (no manifest file)."""
    columns = table.to_arrow().to_pydict()
    return dict(zip(columns["source"], columns["doc_hash"]))  # noqa: B905


def hybrid_search(
    table: lancedb.table.Table,
    text: str,
    vector: list[float],
    k: int = 8,
    rerank: bool = False,
) -> list[dict[str, Any]]:
    query = (
        table.search(query_type="hybrid")
        .vector(vector)
        .text(text)
    )
    if rerank:
        from lancedb.rerankers import CrossEncoderReranker

        query = query.rerank(CrossEncoderReranker())
    else:
        query = query.rerank(RRFReranker())
    return query.limit(k).to_list()
